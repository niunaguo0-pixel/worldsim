# WorldSim 美术圣经（Art Bible）

> **文档说明**：本文档基于概念文档第 5 章"视觉锚点"延展为完整美术圣经，是后续所有美术资产（原画、3D、TA、UI、特效、VFX）的唯一风格基准。核心理念是"微缩沙盘手绘风格"——全时代一套美术语言，文明演进通过建筑形态、技术产物、社会形态的内容变化传达，而非画面风格突变。视觉一致性高于数量：任何资产偏离本圣经须显式标注并经美术总监回批。
>
> **安全红线（强制）**：本圣经含三条 P0 级安全约束——**AX-1（光敏/癫痫安全：危机不用硬闪烁）**、**AX-2（信息不单靠颜色，与 R3 安全阀同优先级）**、**AS-2（世界层灾害/危机图标落地对比兜底：双极兜底 + L6 Overlay，与 AX-2 同优先级 P0）**。三者不可协商、不可默认关闭，落地优先级高于美术偏好。

---

## 1. 视觉身份概述（Visual Identity Overview）

**一句话定义**：WorldSim 的视觉身份是"桌面上的活微缩世界"——玩家俯瞰一座手绘质感的微缩沙盘，万物以低多边形 + 手绘纹理呈现，始终维持统一的温润质感与尺度感。

**核心视觉理念：全时代统一微缩沙盘风格（Unified Diorama Style）**

本作最重要的视觉决策（概念文档 §5.1）：美术风格全时代统一。无论文明处于远古洪荒还是现代都市，画面始终保持一致的微缩沙盘视觉语言。文明从茅棚到城邦到都市的演进，通过建筑形态、聚落规模、技术产物的变化来传达，画面风格本身始终如一。

| 原则 | 说明 |
|------|------|
| 风格统一 | 全时代一套美术风格，不因文明阶段切换画风——时代感来自内容（建筑/技术/社会形态），不来自画风突变 |
| 微缩尺度 | 世界像一座可俯瞰的掌中微缩模型，有"桌面上的一盘小世界"的亲昵感与尺度感 |
| 手绘温度 | 低多边形 3D + 手绘纹理（Hand-Painted Texture），NPR 非写实渲染，画面有"人手做出来"的温度感 |
| 俯视可读 | 所有美术资源服务于俯瞰视角下的信息可读性——玩家一眼读懂地形、聚落、状态 |

**六大风格关键词**（与概念文档 §5.1 对齐）：

1. **微缩沙盘（Diorama）** — 可俯瞰的掌中世界尺度感
2. **手绘温度（Hand-Painted Warmth）** — 手绘纹理赋予画面温度感与匠人气质
3. **层次分明（Layered Depth）** — 地形高低、植被疏密、聚落分布形成纵深
4. **生机盎然（Lived-in Vitality）** — 炊烟、田垄、兽迹、水纹都在动
5. **史诗质感（Epic Texture）** — 微缩尺度中蕴含宏大气象
6. **俯视可读（Top-Down Readability）** — 俯瞰视角下一切信息一目了然

**视觉目标**：玩家从开局到终局看到的是同一个世界的同一种画风——微缩沙盘上手绘质感的小世界。文明演进通过内容变化（建筑形态、聚落密度、技术产物）传达，画面风格本身始终如一。

| 文本/图形 | 前（v2.0.0 草稿） | 对比度 | 判定 | **本版修订（v1.0.0）** | 修订后对比度 |

| **暖金关键数值（F1）** | 暖金 `#D4A84B` 文本 on 暖白 | **1.95:1** | ❌ 严重失败 | **改为深褐文本 `#3A2A1A` + 暖金 `#D4A84B` 边框/下划线装饰（金色仅装饰，信息在文字）；深色主题下暖金可作文本** | **文本 12.1:1 ✅ AAA**；暖金 on 深底 `#1F1812` **7.9:1** ✅ AA |

## 3. 形体与比例（Form & Proportion — 微缩沙盘低多边形）

### 3.1 几何语言

| 维度 | 规范 | 说明 |
|------|------|------|
| 建模方式 | 低多边形（Low-Poly） | 面数克制、轮廓清晰、可读优先 |
| 比例感 | 微缩沙盘 | 世界像掌中模型；建筑/生物比例服务于"俯瞰可读"而非写实 |
| 描边 | **强制细描边（可读性兜底）** | 建筑/角色/标记统一深褐 `#3A2A1A` 细描边（≥1.5px 等效），保证俯视下轮廓可辨、满足 ≥3:1 图形对比（A1） |
| 光影尺度 | 微缩阴影 | 短投影、小偏移，营造"小世界"尺度感 |

### 3.2 相机与尺度

| 项 | 设定 | 理由 |
|----|------|------|
| 相机 | 正交相机（Orthographic）+ 可选透视微调 | 俯视沙盘视角，正交保证一致性 |
| 角度 | 45°–60° 倾斜俯视 | 兼顾地面布局与微缩纵深 |
| NPC 屏幕等效 | 3–5mm（最小可视） | 俯视极小；远处降级为点状 sprite 保底（A1） |

### 3.3 NPC 令牌规范（可读性与可辨性兜底）

> 直接响应上轮缺陷"农职业 NPC 置青绿农田 ≈1:1"与风险 A1（地形与 NPC 明度差 ≥30%）。

每个 NPC 令牌（无论职业/状态）**强制**具备以下三层可读结构，确保不靠颜色辨识：

1. **深色描边**：深褐 `#3A2A1A` 轮廓 ≥1.5px 等效，描边对地（含青绿农田 `#5B8C5A`）对比 ≥3.5:1（≥3:1 图形对比 ✅）。
2. **地面投影盘（AS-1 修订：alpha 40%→60%）**：令牌下方一层半透明深色盘（`#000000` @ ~60% alpha，原 40% 过淡、Z1 距离下阴影几乎不可见；提至 60% 增强地面分离度，vs 青绿农田 2.14:1），将令牌与任意地形底色物理隔离。
3. **职业字形（icon，非颜色）**：农=麦穗 / 猎=箭 / 工=锤 / 管理=冠。职业区分**绝不只靠服饰色**。

职业体色（服饰）作为辅助识别，农职业改用更亮叶绿 `#7CB342`（区别于农田 `#5B8C5A`），但体色差异不承载"可辨性"职责——描边+投影盘+字形才是兜底。

NPC 状态可视化（同样不靠颜色单通道）：

| 状态 | 视觉标记 | 颜色（图形用） |
|------|---------|----------------|
| 正常 | 无额外标记 | 服饰色 |
| 饥饿 | 头顶图标（饭碗）+ 文字标签"饥" | 朱砂 `#C0392B` 图标 |
| 疾病 | 头顶图标（十字）+ 文字标签"病" | 灰绿 `#4A6B4A` 图标 |
| 死亡 | 躺倒 + 渐隐 + 文字标签"亡" | 灰色渐隐 |
| 英雄/关键个体 | 暖金 `#D4A84B` 描边光环 + 文字标签"英" | 暖金（图形） |

### 3.4 空间层级（俯视七层 L0–L6）

| 层级 | 内容 | 渲染方式 |
|------|------|----------|
| L0 底层 | 海洋/大水体 | 半透明水面 + 深浅渐变 |
| L1 地形层 | 山脉/平原/森林/荒漠 | 高度图 mesh + 手绘纹理 |
| L2 植被层 | 草地/树木/灌木 | 低模 + 手绘纹理 |
| L3 建筑层 | 聚落/城市/基础设施 | 低模 + 手绘纹理 |
| L4 动态层 | NPC/动物/天气粒子 | 粒子/点状 sprite（NPC 见 §3.3） |
| L5 特效层 | 干预光效/灾害特效 | 粒子 + shader |
| L6 UI 叠加层 | 标记/面板/光标 | uGUI Canvas（见 §6） |

## 4. 材质与手绘纹理规范（Material & Hand-Painted Texture）

| 材质类型 | 实现方式 | 说明 |
|----------|---------|------|
| 地形 | 高度图驱动 mesh + 手绘纹理 | 程序化高度图，手绘纹理按高度/坡度分配 |
| 水面 | 半透明 + 波纹法线 + 简单反射 | 不追求写实，保持手绘质感 |
| 植被 | 低多边形 + 手绘纹理 | 树冠/草丛低模 + 手绘叶纹 |
| 建筑 | 低多边形 + 手绘纹理 | 木纹/瓦片/砖石均为手绘风 |
| NPC | 低多边形 + 纯色 + 简单纹理 + **强制描边** | 俯视极小，以颜色+轮廓+字形区分职业（§3.3） |

**手绘纹理规范**：
- 笔触可见、有"画上去"的质感，避免冷冰冰纯 CG 感。
- 笔触尺度需与俯视距离匹配——远处看是色块、近处看是笔触（呼应 A1）。
- 无 PBR 写实材质，所有材质走手绘风，不依赖物理光照计算。
- 同类资源合并 **Texture Atlas（2048×2048）** 减少 Draw Call。

**线条与笔触**：地形轮廓自然曲线；水面规整波纹有方向性、半透明；植被叶形可辨但不写实；建筑直线为主但有手绘温度；NPC 简化人形可辨姿态。

## 5. 光照与 NPR 后处理（Lighting & NPR Post-processing）

### 5.1 光照方向

| 光照项 | 设定 | 理由 |
|--------|------|------|
| 主光源 | 柔和方向光（45°–60° 倾斜） | 模拟自然日光，配合俯视相机 |
| 环境光 | 全局环境光（天空色驱动） | 阴影面不过暗，维持手绘质感 |
| 阴影 | Soft Shadows，Shadow Distance ≤ 50m | 微缩尺度短阴影距离，保性能 |
| 阴影偏移 | 小偏移、短投影 | "小世界"尺度感 |
| 四季色温 | 全局光照色温随季节变化 | 春暖 → 冬冷 |
| 灾害光照 | 灾害时全局压暗 + 偏色（渐变，不硬切） | 见 §2.4 |
| 暖色点缀 | 聚落炊烟区域微弱暖色点光 | "有人住"的生机感 |

### 5.2 NPR 渲染定位

NPR（Non-Photorealistic Rendering）手绘卡通风：低多边形建模 + 手绘纹理；柔和方向光 + 环境光，阴影柔和不锐利；边缘光（Fresnel Rim Light）增强物体轮廓可读性；无 PBR、无 TAA（微缩尺度下 TAA 可能抖动，改用 FXAA/SMAA，见 §8）。

### 5.3 后处理调色（URP Volume）

季节/灾害调色经 URP Volume 的 Color Adjustments（色温/对比/饱和度）+ Color Filter（LUT）实现：

| 后处理项 | 设定 | 理由 |
|----------|------|------|
| Saturation | -20% | 压低饱和度，维持手绘温润 |
| Contrast | +0%（自然） | 文本对比由 UI 实色卡保障，不依赖世界对比 |
| White Balance（色温） | 随季节动态（+300K 春 ~ -400K 冬） | 季节色温轮转 |
| Bloom | 弱（干预光效 + 炊烟暖光） | HDR 柔和光晕 |
| Vignette | 弱 | 微缩沙盘聚焦感 |
| Tonemapping | Neutral | 中性色调映射 |
| Color Grading LUT | 四季 LUT（×4，参数化叠加灾害偏色） | 季节/灾害调色 |

> **关键原则**：后处理只调"世界渲染层"。UI 文本对比由 §6.1 的实色内容卡锁定，不受季节/灾害压暗侵蚀（直接修复上轮 F3 风险）。

## 6. UI / 图标体系（UI / Icon System）

### 6.1 统一 UI 风格与面板兜底（修复 F3）

- **整体**：半透明手绘风面板、简洁图标、可读性优先；全时代统一。
- **面板结构（双层）**：面板**容器**可 85% 半透明（不遮挡世界），但**文本承载的内容卡**必须为 **暖白 `#F5F0E8` 100% 不透明**圆角卡 + 深褐 `#3A2A1A` 细边框。→ 文本永远落在实色底，**不受世界底色/灾害压暗/雪原侵蚀**（修复 F3）。
- **字体**：全部 UI 文本走 **TextMeshPro SDF 矢量字体**（禁用位图字体，否则缩放糊化）；基准 100%，CJK 小字号保笔画完整（正文用思源黑体/HarmonyOS Sans 等无衬线，不用手绘装饰体作正文）。
- **按钮**：圆角方块 + 悬停高亮（深褐边框 / 暖金边框，非纯色填充文本）。

### 6.2 图标系统（形状编码为主、颜色为辅）

> 落实 WCAG 1.4.1"信息不单靠颜色"（AX-2 基础）。所有意义通道同时具备形状/图标 + 文字标签。

| 标记类型 | 形态（形状编码） | 色彩（图形用） | 文字标签 |
|----------|------------------|----------------|----------|
| 聚落 | "屋"形图标 + 人口数值 | 深褐 `#3A2A1A` | 名称/人口 |
| 物种 | "足印"图标 | 深褐 `#3A2A1A` | 物种名 |
| 资源 | "圆点"图标 + 数值 | 深褐 `#3A2A1A` | 资源名 |
| **灾害/前兆** | **朱砂惊叹三角图标** | 朱砂 `#C0392B`（图形） | **"旱灾前兆"等文字** |
| **紧急/危机** | **朱砂双环惊叹图标** | 朱砂 `#C0392B`（图形） | **"文明存亡危机"等文字** |
| 干预落点 | 金色光环 + 涟漪 | 暖金 `#D4A84B` | — |
| 正向状态 | 青绿圆点 + 标签 | 青绿 `#5B8C5A`（图形） | 状态文字（深褐） |

> **[v1.0.1 强制约束 — AS-2（P0）世界层灾害/危机图标双极兜底 + L6 Overlay]** 实测朱砂 `#C0392B` 灾害图标直接落世界底色时 vs 赭石 `#8B5E3C` / 岩石灰 `#6B6B6B` 仅 **1.03:1**、vs 青绿 `#5B8C5A` **1.38:1**、vs 土黄 `#C4A35A` 2.26:1，全线 <3:1（朱砂中等明度与大地色系明度接近）——灾害前兆是 R3 安全阀信息，故**升格 P0**，与 AX-2 并列。所有**世界层标记**（聚落/物种/资源/灾害/干预/国家覆盖）强制具备：① **暖白底板 `#F5F0E8`**（圆/圆角，外扩 ≥ 图标 20%，承运暗/中调底：vs 赭石 4.92:1 / 岩石灰 4.7:1 / 青绿 3.46:1 / 水面 3.99:1 ✅）；② **深褐描边 `#3A2A1A` ≥2px 屏幕等效**（承运亮调底：vs 土黄 5.70:1 ✅）；③ **渲染于 L6 Overlay（uGUI Canvas，后处理之后，见 §3.4）**，灾害偏色/压暗/雪原不侵蚀标记对比（与 §6.1 内容卡修 F3 同构）。双极互补：任何大地色恒有一极 ≥3:1（土黄上暖白底板仅 2.12:1 由描边补；岩石灰上深褐描边仅 2.58:1 由底板补）。**本约束与 AX-2（图标+文字冗余）并列 P0，不可协商、不可默认关闭。** 渲染路径技术可行性已确认：`docs/architecture/worldsim-architecture.md` v1.0.2 §12 已确认 AS-2 之 URP L6 Overlay（世界层灾害/危机图标渲染于后处理之后）技术路径可行（Render Objects Renderer Feature + `AfterRenderingPostProcessing` + 专用 Rendering Layer）；**Sprint 01 仅需验证集成选择**（uGUI 世界空间 Canvas vs Sprite/Quad + 专用 Rendering Layer），须在季节 + 灾害调色 Volume 激活下截图比对，确认标记对比不受侵蚀、世界锚定稳定。

### 6.3 关键 UI 元素

- **信息面板**：可折叠侧边，默认收起；三层（总览→详情→逐项）；**关键数值 = 深褐文本 + 暖金边框/下划线**（非暖金文本，修复 F1）。
- **时间轴**：底部细条，季节/年份标注，可拖拽/点击设值（替代拖拽以助可访问性）。
- **事件提示（右侧滑入卡）**：约 0.3s 滑入；**不瞬时消失**——进入可滚动、可回看的通知日志（与干预系统历史面板、S6 编年史同源）；紧急/关键事件持续至玩家确认。
- **编年史**：全屏阅览，暗色铺底，可搜索/筛选/缩放（缩放与全局字体缩放联动）。
- **事件分级（视觉）**：

| 级别 | 视觉编码（图标+文字，非纯色） | 图形色 |
|------|-------------------------------|--------|
| 正面 | 暖金图标 + 文字"丰/发/灵" | 暖金 `#D4A84B` |
| 中性 | 深褐图标 + 文字 | 深褐 `#3A2A1A` |
| 警告 | 朱砂惊叹三角 + 文字"告" | 朱砂 `#C0392B` |
| **紧急** | **朱砂双环惊叹 + 文字"急" + 平滑脉冲（见 AX-1）** | 朱砂 `#C0392B` |

### 6.4 AX-1 在 UI 的体现（P0 安全项）

紧急/危机事件**禁止硬闪烁（hard flash / 频闪）**为默认表现。默认采用：
- **平滑脉冲（呼吸）**：朱砂图标/边框明度在 ~1.5–2s 周期内缓变（0%→100% 缓入缓出，**无瞬变黑/白跳变**），肉眼可感但不触发光敏。
- 叠加图标 + 文字（AX-2），意义不依赖动效本身。
- **硬闪烁（频闪）仅作可关闭选项，默认 OFF**；开启路径在设置 → 可访问性 → "危机频闪（实验性，光敏风险）"，需二次确认。

## 7. 可访问性章节（Accessibility — 强制约束）

> 本作是中文上帝视角俯瞰模拟，"读世界即玩法"——可读、可辨、可控即核心循环可达性底座，故可访问性为基础要求而非锦上添花。本圣经承载美术侧编码；UX 规格（`design/accessibility-requirements.md`，概念文档 §规划、Phase 2 待产出）须引用本分级。

### 7.1 三条 P0 安全约束（不可协商）

**AX-1 — 危机不用硬闪烁（光敏/癫痫安全，与 WCAG 2.3.1 对齐）**
- 灾害/文明存亡危机的视觉提示**默认平滑脉冲 + 全局"减少动态/无闪烁"开关兜底**（见 §8.4）。
- 硬闪烁（sub-3Hz 频闪或任何瞬变 on/off）仅作可关闭选项，**默认关闭**，开启需二次确认。
- 落地：§6.3 事件分级"紧急"、§6.4。优先级 **P0 安全项**。

**AX-2 — 意义不单靠颜色（与 R3 安全阀同优先级 P0）**
- 灾害/紧急提示必须同时具备 **图标 + 文字**冗余；颜色仅作强化，不作唯一通道（WCAG 1.4.1）。
- **音频冗余由 audio-director（阮和鸣）后续补全**——本圣经仅做视觉编码占位（图标+文字已具备），音频通道待 `design/accessibility-requirements.md` / 音频 GDD 接入。
- 落地：§6.2 图标系统、§3.3 NPC 字形、§6.3 事件卡。优先级 **P0（与 R3 同档）**。

**AS-2 — 世界层灾害/危机图标落地对比兜底（与 AX-2 同优先级 P0）**
- 世界层（L6 Overlay）的灾害/危机/标记图标必须采用"双极兜底"：**暖白底板 `#F5F0E8` + 深褐描边 `#3A2A1A`**，渲染于 L6 Overlay（后处理之后），确保落任何大地色底均 ≥3:1 图形对比（WCAG 1.4.11）。
- 理由：朱砂灾害图标直接落赭石/岩石灰底实测仅 1.03:1，灾害前兆是 R3 安全阀信息，不可不可辨（与 AX-2 同源，属"读世界即玩法"可达性底座）。
- 落地：§6.2（世界层图标双极兜底强制约束）。优先级 **P0（与 AX-2 同档）**。

> **协同点（待 Phase 4 排期）**：AX-2 的"意义不单靠颜色"是**视觉编码**层；其背后的**灾害前兆安全阀设计**（何时预警、预警时长、前兆信号的内容）由 **design-strategist（文策渊）协同 S2 生态模拟 / S6 涌现叙事**负责（R3 安全阀的设计侧）。美术总监只负责把前兆/危机信号做成语义冗余的视觉编码（图标+文字+非频闪动效），不定义预警逻辑本身。该协同在 Phase 4 排期，本圣经已预留接口（§6.2/§6.3 的形状+文字编码可承载任意灾害类型）。

### 7.2 上轮对比度缺陷修订（已落本圣经）

| 缺陷 | 原值 | 修订方案（落位） | 修订后 |
|------|------|------------------|--------|
| F1 暖金关键数值 | 1.95:1 失败 | 深褐文本 + 暖金边框/下划线；暖金文本限深色主题（§2.2 / §6.1） | 文本 12.1:1 ✅ AAA |
| F2 青绿状态文本 | 3.5:1 失败 | 深褐文本 + 青绿状态点/图标；绿调文本用暗绿 `#2F5330`（§2.2 / §6.2） | 文本 12.1:1；暗绿 7.7:1 ✅ AAA |
| F3 半透明面板侵蚀 | 世界底色侵蚀文本 | 文本落 100% 不透明暖白内容卡（§6.1） | 文本恒 ≥12:1，不受世界底色影响 |
| A1/NPC 农田 ≈1:1 | ≈1:1 不可辨 | 强制描边 + 地面投影盘 + 职业字形；农用亮叶绿（§3.3） | 描边对地 ≥3.5:1（≥3:1 图形 ✅），不靠颜色辨职业 |

### 7.3 三档映射（与项目范围分层对齐，本版确认不变）

| 档位 | 含义 | 计划落地范围 |
|------|------|--------------|
| **Basic（基础档）** | 每可发布构建必备底线 | **MVP** |
| **Standard（标准档）** | 严肃 PC 模拟应有质量 | **核心层** |
| **Comprehensive（完备档）** | 示范性细粒度定制 | 延展/远景层 |

**确认**：MVP=Basic、核心层=Standard 的映射**不变**（详见 `docs/art/accessibility-grade.md` 特性矩阵）。本圣经已把 Basic 六项（SDF 字体、形状编码标记、持久通知日志、无 TAA、热键可重映射、无硬闪烁）作为架构预埋写入规范，核心层 Standard（CVD 模式、高对比主题、减少动态总开关、全局字体缩放、完整键盘导航、可检索日志）由 §8 后处理接口支撑。

## 8. 技术美术对接（Technical Art Interface / URP Volume）

### 8.1 URP 渲染管线配置

| 配置项 | 设定 | 理由 |
|--------|------|------|
| 渲染管线 | URP 17.0.4 | 概念文档已确认 |
| 相机 | 正交 + 可选透视微调 | 俯视沙盘 |
| 抗锯齿 | FXAA 或 SMAA | 性能优先；微缩尺度 TAA 可能抖动（无 TAA → 无运动模糊风险） |
| 色彩空间 | Linear | shader/后处理色彩准确 |
| HDR | 开启 | Bloom（干预光效）需 HDR |
| MSAA | 关闭（FXAA 替代） | URP 下与部分 shader feature 不兼容 |

### 8.2 统一 Shader 方案

**WorldSim Hand-Painted Shader**（URP Shader Graph，NPR 手绘风）：
- 输入：Base Color（手绘纹理）、Normal（可选）、Occlusion（可选）、Rim Light Color（边缘光增强可读性）。
- 逻辑：基础色采样 → 柔和方向光+环境光（降 PBR 权重）→ Fresnel 边缘光 → 全局饱和度后处理。
- 变体：WorldSim Hand-Painted（建筑/地形/植被，≤5）、WorldSim Water（≤3）、WorldSim NPC（≤3，Instancing）、WorldSim VFX（≤5）、UI Default（URP 内置）。核心 Shader ≤5，变体总数 ≤20。

### 8.3 性能预算

| 项目 | 预算 |
|------|------|
| 渲染帧时间 | ≤ 12ms @ 1080p（余给模拟） |
| Draw Call | ≤ 2000（Instancing 后） |
| 三角面数 | ≤ 2M |
| **粒子数** | **≤ 5000 同屏（见 §8.4 可调上限）** |
| 纹理内存 | ≤ 2GB（Atlas + 压缩） |
| Shader 变体 | ≤ 20 |

策略：GPU Instancing、DOTS/ECS（NPC/生态）、LOD Group（3 级 + Billboard）、Tick-based 模拟、视锥剔除、HLOD、粒子对象池。

### 8.4 可访问性后处理接口（TA 经 URP Volume 实现，P0 落地要求）

技术美术（TA）须经 URP Volume + 游戏内设置实现以下可访问性开关，**全部为游戏内自实现开关（桌面 PC 不能只靠 OS 同步）**：

| 开关/接口 | 实现方式（URP Volume + 设置） | 对齐约束 |
|-----------|-------------------------------|----------|
| **高对比主题** | 独立 Volume Profile / UI 样式表切换为深色主题（深褐黑 `#1F1812` 底 + 暖白文本 15:1、暖金文本 **7.9:1** ✅ AA）；不改动世界渲染核心，仅 UI 样式 + 轻量对比增强 | 修复 F1（暖金在深底可用）；Standard 档 |
| **减少动态 / 无闪烁** | 全局标志位驱动：① 危机脉冲强制为静态稳态（AX-1）；② 季节 lerp 平滑/即时化；③ Bloom 衰减；④ 非必要天气粒子削弱/关闭；⑤ 相机与 LOD 跳变过渡平滑 | AX-1 安全兜底；Standard 档 |
| **粒子数量上限可调** | 暴露同屏粒子上限（预算 ≤5000）为设置项；"减少动态"开启时自动下调 | 性能档兼晕动缓解档；并入减少动态 |
| **字体缩放滑块** | 全局 UI 文本缩放 75%–150%（相对单位布局不破版），与编年史缩放联动；最小字号下限 ≥12px@1080p | Basic 预埋 SDF；Standard 滑块 |
| **色觉缺陷（CVD）模式** | 永久强制"图标+文字标签"叠加；易混色对（青绿↔土黄、朱砂↔赭石）安全化重映射/加图案；危险信息非红色编码（三角符+边框） | 3.1/3.7；Standard 档 |

**`com.unity.modules.accessibility` 1.0.0 的使用边界**：该 Unity 内置无障碍模块**仅作 OS 默认值的来源**（如读取 OS reduce-motion / 粗体偏好作为游戏内开关的初始勾选建议），**绝不**作为唯一同步通道——游戏内设置必须自实现、独立生效，确保桌面 PC 玩家不依赖系统设置即可获得完整可访问性。

**接口契约（供程基岩/TA 对齐）**：设置菜单暴露上述开关 → 写入 `AccessibilitySettings` 运行时配置 → 驱动 URP Volume Override 与 UI 样式表；Volume 使用 Global（基础后处理）+ Local（灾害区域）组合，可访问性覆盖层优先级高于季节/灾害调色。

类型前缀：BLD 建筑 / VEG 植被 / CHR 角色 / CRE 生物 / TER 地形 / VFX 特效 / UI 界面 / TEX 纹理 / MAT 材质 / SHD Shader / MOD 模型 / ANM 动画 / **VOL 后处理 Volume Profile（v1.0.1 新增顶层前缀）**。

> **[v1.0.1 命名扩展]**（与 asset-spec v1.0.1 §1.3 对齐）三类资产超出原前缀表，现扩展并强制：
> - `VOL_`：后处理 Volume Profile（独立于 BLD/VEG/... 的顶层前缀），如 `VOL_ACCESS_HIGHCONTRAST`、`VOL_DISASTER_DROUGHT`。
> - `UI_ICO_`：`UI_` 下二级分类"UI 图标"，如 `UI_ICO_HAZARD_DROUGHT`（灾害/危机图标须成对交付文字标签键，AX-2）。

> - `TEX_LUT_`：`TEX_` 下二级"调色 LUT"，如 `TEX_LUT_SEASON_AUTUMN`、`TEX_LUT_HAZ_DROUGHT`。

### 9.3 LOD 策略

| LOD | 距离（正交 Size 倍数） | 面数 | 表现 |
