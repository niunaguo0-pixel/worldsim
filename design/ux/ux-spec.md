# WorldSim UX 规格（UX Specification）

> 本文是 Phase 4 预制作中"UX 规格"职责项的产出。它把概念文档、S1 干预、S2 生态、S4 时间三份 GDD 与美术圣经、可访问性分级，收敛为一份**玩家如何读世界、如何干预世界**的体验蓝图。
> 红线重申：**玩家不下场**——agency 来自"可见的因果影响力"，而非资源稀缺；**无认知过载**（R5）、**无支柱漂移**、**无主导策略**。

## 1. 设计目标与红线对齐（Design Goals & Red-line Alignment）

### 1.1 UX 层设计目标

| 目标 | 对应系统风险 | 说明 |
|------|--------------|------|
| **让"不下场"也能感到 agency（代理感）** | R1（S1） | 通过"干预印记 + 因果链追溯 + 历史档案"三件套，使玩家把世界变化归因到自己（§3.2/§3.3） |
| **让异步延迟后果可理解** | R1·R2（S1/S4） | 干预不即时生效，UI 以"待生效微光→渐变到位→远期后果回指"表达因果（§3.2） |
| **防止认知过载** | R5（S8） | 信息分层（总览→详情→逐项）、智能事件筛选、可关注焦点（§2 / §5.3） |
| **R3 安全阀可读可达** | R3（S2） | 灾害前兆在应力区即预警，给 3–6 游戏月反应窗口；AX-2 冗余确保色弱玩家不丢安全阀（§9） |
| **高速下不丢预警** | R14（S4） | 20× 加速下弱化细节、强化预警、引导减速响应（§4.4 / §9.4） |

### 1.2 红线自检

- **无认知过载**：所有面板默认收起，信息密度随尺度/速度自适应（§4.4），非焦点信息不挤占主视野。
- **无支柱漂移**：核心循环三面板（生态/文明/威胁）始终同屏可达，单面板不孤立呈现（§2.1）。
- **无主导策略**：干预类型无数值优劣排序，UI 不暗示"最优干预"；反噬预警是**软引导**而非硬性限制（S1 §2.1）。
- **不下场红线**：光标是"参数调节指针"而非"单位选择器"；选取用于读取状态/设定落点，绝不下达个体命令（§3.1）。

## 2. 信息架构（Information Architecture）

### 2.1 核心面板清单

世界是主角，UI 是辅助工具。五类核心面板均**默认收起**（半透明容器 + 暖白实色内容卡，art-bible §6.1），按需展开，不遮挡主视野。

| # | 面板 | 职责 | 数据来源 | 默认态 |
|---|------|------|----------|--------|
| P1 | **世界总览 World Overview** | 全局生态指标、季节/年/时代、国运聚合、当前速度 | S2 生态指标(3/5项) + S4 时钟 + S3 国家聚合 | 顶部极简条常驻（仅关键数） |
| P2 | **当前聚落 Current Settlement** | 选中聚落详情：人口/粮储/经济/科技/稳定度/发展倾向 | S3 聚落态 | 选中后展开 |
| P3 | **文明 Civilization** | 多聚落/国家层聚合统计（核心层）：总人口/总产出/总军力/稳定度 | S3 国家聚合（仅聚合统计，不逐人） | 多聚落模块 ON 时可用 |
| P4 | **编年史 Chronicle** | 全屏阅览：事件时间线、可搜索/筛选/缩放 | S6（待建）事件序列 | 全屏覆盖，按需打开 |
| P5 | **干预光标上下文 Intervention Cursor Context** | 干预模式下：类型/参数预览/作用范围/反噬风险/近期同区记录 | S1 pending/反噬追踪器/历史 | 干预模式激活时跟随 |

### 2.2 导航层级（Navigation Hierarchy）

```
[主视图：世界地图（正交俯视）]
   │
   ├─ 顶部常驻：世界总览条 P1（极简：季节·年·时代·全局生态灯·速度）
   │
   ├─ 左侧边缘标签（点击/Tab 呼出，半透明侧栏）
   │     ├─ P2 当前聚落（依赖选中态；未选则提示"点击地图选取聚落"）
   │     ├─ P3 文明（核心层；MVP 单聚落时折叠为 P2 同视图）
   │     └─ P4 编年史（全屏覆盖，Esc/关闭返回）
   │
   ├─ 底部：时间轴 + 速度控件（暂停/1×/2×/5×/20×）+ LOD 指示（§4.3）
   │
   ├─ 右侧：事件通知滑入卡 + 持久日志入口（§5）
   │
   └─ 光标上下文 P5（干预模式激活时浮现；§3）

导航原则：
  · 总览(P1) 始终可达；详情(P2/P3) 依赖"选取态"，无选中不空占屏。
  · 编年史(P4) 为全屏模态视图，打开时世界暂停建议（不强制）。
  · 全部面板支持键盘焦点遍历（Tab/Shift+Tab + 方向键），不依赖鼠标（§6）。
```

### 2.3 关注焦点（Focus / 防认知过载 R5）

- 玩家可"关注"某聚落/某区域（星标），右侧日志仅优先推送关注对象的事件（智能筛选，S8 实现）。
- 未关注对象仅入后台日志，不弹卡——避免"什么都想管"的焦虑（S1 IV5）。

## 3. 交互模型（Interaction Model — 间接干预）

### 3.1 核心立场：光标是"参数指针"，不是"单位选择器"

玩家不下场。所有操作通过"光标 + 面板"完成：
- **光标** = 世界坐标指针，用于在地图选取位置/区域/聚落，或设定干预落点。
- **面板** = 读取状态（P2/P3）、选择干预（P5）、查阅事件（P4）。
- 绝不允许：选中个体 NPC、拖动单位、下达移动/攻击指令（架构红线 + 概念 §2.3）。

### 3.2 间接干预光标操作流程（核心循环"③ 施加干预"的 UX 落地）

```
[常态：观察] ──按 I / 点干预工具栏──▶ [干预模式]
                                              │
                              ┌───────────────┴───────────────┐
                              ▼                                ▼
                     [选干预类型]                      [选目标]
              气候调节/资源投放/文明引导…          移动光标到地图落点
              （MVP：增雨·减雨·水源·可种地·农/猎倾向）   （异步延迟生效，落点显"待生效"微光）
                              └───────────────┬───────────────┘
                                                ▼
                                         [调参预览]
                              显示：作用范围(涟漪半径) + 预计参数变化
                              + 反噬风险（同区近期同类干预计数，§3.4）
                                                ▼
                                         [确认施放 Enter]
                              → 金色光环 + 涟漪即时反馈（art-bible §6.2）
                              → 落点保留淡金"行动印记"微光（持续 1 游戏月，R1）
                              → 参数进入 S1 pendingQueue，异步延迟生效（§3.3）
                                                ▼
                                         [返回观察]（世界继续推进）
```

### 3.3 异步延迟生效的反馈表达（让玩家理解因果 — R1·R2·S4）

干预不即时改变世界。UX 用四层反馈表达"我做了什么、何时生效、后果从哪来"：

| 层级 | 反馈 | 时机 | 设计意图 |
|------|------|------|----------|
| **① 即时印记** | 施放处金色光环+涟漪（art-bible §6.2）；落点保留淡金微光**1 游戏月**作为"我的行动印记" | t=施放时刻 | 让玩家感到"我做了什么"（R1 即时回应感） |
| **② 待生效** | 落点微光由淡金渐变为"参数渐变中"态（如降雨区云量缓增），不硬切 | t→t+1 游戏月渐变到位（S1 §2.2.1：降雨 1 月内渐变） | 表达"延迟生效"，非即时可控（R2） |
| **③ 渐变响应** | 生态/文明指标趋势箭头（Rising/Falling）与数值缓变；视觉量（植被/水面）平滑插值 | t+1 月起逐 pass 显现 | 玩家可观察"正在发生"（S2 §2.7 指标更新） |
| **④ 远期回指** | 远端后果（3–12 游戏月后）显现时，UI 提示"此事件源于 N 游戏月前的干预"（时间戳锚定，S1 causalChainNode） | t+Δ 后果显现 | 因果链可归因，闭环 agency（S1 IV2 / V3） |

> **因果理解三件套（R1 攻关）**：① 行动印记（印记微光）② 干预历史档案（P5 历史记录，可翻阅自己的干预）③ 远期回指提示（时间戳）。三者共同使"世界的变化"归因到"我的决策"。

### 3.4 反噬预警 UI（软引导，非硬性限制 — S1 §2.1 / IV4）

反噬是"世界推回"，不是系统惩罚。UX 表达：

- **预警时机**：同区域同类型干预接近反噬阈值时（如降雨 3 月内已 2 次），P5 显示"该区域近期降雨频繁，继续增雨可能引发洪涝"（S1 §2.1 阈值表）。
- **预警形式**：暖金边框 + 文字标签（**非朱砂**——反噬预警是"建议收手"不是"危机"）；图标用"回旋箭头"形状编码，不依赖颜色（AX-2）。
- **预警窗口**：2–3 游戏月预警（S1 IV4），给玩家调整空间；反噬严重度与过度程度成正比。
- **不阻断**：预警不灰化/不禁止施放，仅软提示（玩家仍可选择继续，承担自然后果）。

### 3.5 地图标记与选取（Selection & Markers）

标记全部遵循 art-bible §6.2 **形状编码为主、颜色为辅**（AX-2）：

| 标记 | 形状 | 文字标签 | 选取交互 |
|------|------|----------|----------|
| 聚落 | "屋"形图标 | 名称+人口 | 点击/键盘聚焦 → 打开 P2 |
| 物种 | "足印"图标 | 物种名 | 点击 → 生态详情浮层 |
| 资源 | "圆点"图标 | 资源名+数值 | 点击 → 资源浮层 |
| 灾害/前兆 | 朱砂惊叹三角 | "旱灾前兆"等文字 | 点击 → 预警详情（§9） |
| 危机 | 朱砂双环惊叹 | "文明存亡危机"等文字 | 点击 → 危机详情（§9） |
| 干预落点 | 金色光环+涟漪 | — | 不可选取（仅视觉印记） |
| 正向状态 | 青绿圆点+标签 | 状态文字（深褐） | — |

- **选取 = 读取/设落点**，绝不选个体。选中态以暖金边框高亮（art-bible §2.3）。
- 键盘选取：方向键移动光标栅格，Enter 选中/确认（§6）。

## 4. HUD 布局草案（含时间尺度联动 LOD）

### 4.1 主屏幕布局示意（ASCII）

```
┌──────────────────────────────────────────────────────────────────────┐
│ [P1 世界总览条] 春·第3年·远古  │ 生态灯:●稳态  │ ⏸1×2×5×20×        │ ← 顶部常驻
├──────────┬────────────────────────────────────────────┬──────────────┤
│ [左栏]    │                                            │ [右栏]        │
│ 总览 P1  │           世 界 地 图（正交俯视）            │ 事件通知卡    │
│ 聚落 P2  │        （微缩沙盘手绘 · 俯视可读）           │ (滑入·不消失) │
│ 文明 P3  │                                            │ ───────────  │
│ 编年史P4 │        ◉聚落  ··物种  ·资源  ⚠前兆         │ 持久日志入口  │
│ [Tab呼出]│                                            │              │
│          │              ✦干预落点(金色印记)            │              │
├──────────┴────────────────────────────────────────────┴──────────────┤
│ [底部] 时间轴 ──春──夏──秋──冬──┤第3年├──  ⏸ │1×│2×│5×│20×│ [LOD:聚落级] │
└──────────────────────────────────────────────────────────────────────┘
   [P5 干预光标上下文] 浮现于角落（干预模式激活时）：
   类型:增雨  范围:1区域  预计:降雨+30% 持续2月  反噬风险:⚠近期已2次(建议收手)
```

### 4.2 面板布局原则（呼应 art-bible §5.5 / §6.1）

- **极简、不遮挡主视野**：容器 85% 半透明，内容卡 100% 不透明暖白（文本恒 ≥12:1）。
- **信息分层**：总览(关键数) → 详情(选中对象) → 逐项(展开细节)，三级折叠。
- **UI 用色 ≤4**：深褐(文字/轮廓) + 暖金(高亮/干预) + 朱砂(警示) + 青绿(正向)，面板底不计入。

### 4.3 时间轴控件（S4 ↔ S8）

- 底部细条：季节(春/夏/秋/冬) + 年标记 + 时代门槛提示。
- 速度：暂停(空格) + 1×/2×/5×/20×（数字键）；**点击设值替代拖拽**（可访问性 §3.4 Standard）。
- 世代节点：文明级世代更替在轴上标"⌘ 世代节点"（可点击看编年史条目）。
- 关联 S4 §4.2：UI 仅暴露 pause/速度倍率，逻辑由 S4 时钟驱动。

### 4.4 时间尺度联动 LOD（HUD 信息密度自适应 — S4 §2.4 / art-bible §3.4 / §9.3）

相机缩放（正交 Size 倍数）与时间加速**联动 HUD 信息密度**，避免近看信息爆炸、远看一片空白：

| 相机正交 Size | 实体 LOD（美术） | HUD 信息密度 | 时间尺度联动 |
|---------------|------------------|--------------|--------------|
| 0–0.5× (近) | L0 全细节 | 显示个体级状态浮层（关键个体/职业字形） | 个体级 LOD |
| 0.5–1.5× | L1 | 聚落级面板(P2)全量 | 聚落级 LOD |
| 1.5–3× | L2 | 聚合统计，弱化个体 | 国家/文明级 LOD（标注"聚合统计"） |
| 3×+ (远) | L3 点 sprite | 仅全局生态灯 + 速度 + 战略标记 | 世代级概览 |

**时间加速联动规则（R14 对策）**：
- **1×/2×**：全信息密度，趋势箭头/数值正常呈现。
- **5×/20×**：① 弱化逐个体动效，仅保战略级标记；② **预警/危机信号强化**（前兆卡置顶、危机平滑脉冲加粗，§9）；③ 时间轴显示"⚠高速：建议减速至 1× 响应应力窗口"提示；④ 引导玩家在高速下可一键减速（不强制）。
- **暂停**：所有插值冻结，玩家无压观察/布署 pending 干预/查阅编年史。

> 联动意图：速度越高，玩家越需要"宏观预警"而非"微观细节"——HUD 随速度自动从"细节模式"切到"预警模式"，呼应 S4 R14 与 S1 IV5（减少焦虑）。

## 5. 事件通知 & 编年史可读性规范（呼应可访问性 AX-2 / 持久日志）

### 5.1 事件通知卡（Event Notification）

- **不瞬时消失**（Basic 底线）：右侧滑入 ~0.3s，进入**可滚动、可回看的持久通知日志**（与 S1 干预历史、S6 编年史同源）。
- **关键/紧急事件持续至玩家确认**（不自动滚出）。
- **分级视觉编码（AX-2：图标+文字，非纯色）**：

| 级别 | 视觉编码（形状+文字） | 图形色 | 持续 |
|------|----------------------|--------|------|
| 正面 | 暖金图标 + 文字"丰/发/灵" | 暖金 | 入日志 |
| 中性 | 深褐图标 + 文字 | 深褐 | 入日志 |
| 警告 | 朱砂惊叹三角 + 文字"告" | 朱砂 | 入日志，建议响应 |
| **紧急** | **朱砂双环惊叹 + 文字"急" + 平滑脉冲（AX-1）** | 朱砂 | **持续至确认** |

### 5.2 AX-2 / AX-1 强制约束（P0 安全项）

- **AX-2（意义不单靠颜色，与 R3 同 P0）**：所有事件/预警/状态**同时具备图标 + 文字冗余**；颜色仅强化（art-bible §6.2/§7.1）。色弱玩家不丢失任何信息通道。
- **AX-1（危机无硬闪烁，P0）**：紧急事件**默认平滑脉冲（呼吸，~1.5–2s 缓变，无瞬变黑/白跳变）**；硬闪烁仅作可关闭选项、默认 OFF（art-bible §6.4）。
- **减少动态总开关**（Standard）：关闭硬闪烁、平滑季节 lerp、衰减 Bloom、削弱天气粒子、平滑 LOD 跳变（art-bible §8.4）——全局生效。

### 5.3 日志可读性（防认知过载 R5）

- **智能筛选**（核心层 Standard）：日志可按 系统(生态/文明/战争/灾害/时代) / 聚落 / 严重度 筛选排序。
- **闭式字幕式呈现**：每条 = 标题 + 简明正文 + 游戏月时间戳（"第3年·春"）。
- **关注焦点**：仅优先推送玩家关注对象事件（§2.3），其余沉底。
- **可检索**：搜索框 + 时间范围筛选。

### 5.4 编年史（Chronicle，P4 全屏视图 — 待 S6 落地对接）

- 全屏阅览，暗色铺底；可搜索/筛选/缩放（缩放联动全局字体缩放）。
- 内容由 S6 涌现叙事引擎生成（**待 S6 落地对接**：本规格定义呈现契约——事件时间线 + 关键个体追踪条目 + 世代节点；S6 负责内容生成与模板匹配）。
- 世界事件记录：沙盒模式下"文明灭绝/生态崩溃"作为**编年史叙事资产**记录（概念 §3.4.1），非惩罚。

## 6. 控制映射与可重映射方案（全键盘可玩）

### 6.1 基础键位（MVP = Basic 档）

间接干预无操作时序压力 → 本作先天适合全键盘（可访问性 §3.4）。

| 动作 | 默认键 | 说明 |
|------|--------|------|

| 干预模式开关 | `I` | 进入/退出 P5 干预上下文 |

| 取消 | `Esc` / 右键 | 退出当前模式/取消选取 |

### 6.2 重映射与完整键盘导航（核心层 = Standard 档）

- **可视化重绑定 UI**：设置 → 控制，列出全部动作，点击后"按新键"捕获；冲突检测 + 重置默认。
- **预设方案**：左手布局 / 右手布局 / 纯鼠标 / 单手（Comprehensive 扩展）。
- **完整键盘导航**：`Tab`/`方向键` 遍历所有面板与控件；时间轴支持"点击/方向键设值"替代拖拽（可访问性 §3.4）。
- **配置档导入导出**（Comprehensive）：多套键位 profile。

### 6.3 与架构边界一致

控制仅产生"玩家输入"→ UI → `InterventionSystem.pendingQueue`；**绝不**直接写 `WorldState`（架构 §2.3 / §5.2）。重映射只改"输入→动作"映射，不改逻辑。

## 7. 新手引导 / 首次运行 Onboarding（沙盒默认模式）

### 7.1 设计立场

- **沙盒默认（无胜利条件）** → 引导应"宽容、探索式"，不制造失败压力（概念 §3.4.1 A）。
- **不阻断模拟**：引导以"提示卡"叠加，玩家可随时暂停/跳过；不强制长教学。
- **教学目标**：让玩家在 10 分钟内完成"观察→第一次干预→理解异步延迟→理解因果回指→知道失败不终止"。

### 7.2 引导步骤（渐进式、可跳过）

| 步 | 内容 | 呈现 | 关联 |
|----|------|------|------|
| 1 | 认识世界：三面板（生态/文明/威胁）同屏可达 | 轻提示卡指向左栏/顶部 | §2 |
| 2 | 第一次干预：在旱情区增雨 | 高亮干预工具栏 + 光标引导落点 | §3.2 |
| 3 | 等待延迟生效：降雨 1 月内渐变到位 | "待生效"微光提示 + 时间轴建议 1× | §3.3 ②③ |
| 4 | 观察后果：植被返青、粮储回稳 | 趋势箭头 + 因果印记微光 | §3.3 |
| 5 | 理解因果回指：远端后果提示"源于 N 月前干预" | 示例事件卡（教学用） | §3.3 ④ |
| 6 | 编年史与通知：世界事件被记录 | 打开 P4 演示 | §5 |
| 7 | 时间轴与速度：快进无聊期、暂停观察 | 速度控件演示 | §4.3 |
| 8 | GoalMode 说明：你在沙盒模式，无胜利条件，失败不终止游戏 | 模式提示卡（指向设置可切换） | §8 |

> 引导卡全部遵循 AX-2（图标+文字）；高速/减少动态下自动降级为静态提示（AX-1）。

## 8. GoalMode UI 规格（呼应概念 §3.4.1）

### 8.1 设计原则（来自概念 §3.4.1）

- **三种模式模拟逻辑完全相同** → UI 只影响"判定与呈现"，绝不改变生态/文明/时间任何模拟规则。
- **达成 ≠ 结束**：里程碑/自定义达成仅播报叙事，玩家可选继续（延续 R8「失败不是终点」→「成功也不是终点」）。
- **随时可切换**：设置内切换（沙盒↔里程碑），不影响存档与世界状态。

### 8.2 New Game 面板（第⑤项）

```
┌─ New Game 设置 ─────────────────────────────┐
│ ① 起始时代： [远古沙盒▼]                     │
│ ② 起始区域： [黄河长江▼]                     │
│ ③ 国界年份： [2026▼]  (仅地缘模式)          │
│ ④ 法律传统偏好：[由区域映射▼] (仅地缘模式)   │
│ ⑤ 目标模式：                                 │
│    (●) A 沙盒 — 无胜利条件（默认）           │
│    ( ) B 里程碑 — 城邦或王国级               │
│    ( ) C 自定义目标 — 自设条目               │
│        [+ 添加条目：让文明活过10代 ▢]         │
└────────────────────────────────────────────┘
```
> 目标模式不进 `WorldInitConfig`（架构 §9.1 / S5 §2.2.1 ⑤ 归属声明），由概念/S3 承载；New Game 仅作 UI 选择。

### 8.3 运行期 HUD 呈现（三种模式）

| 模式 | HUD 呈现 | 失败/达成处理 |
|------|----------|---------------|
| **A 沙盒** | 顶部无胜利进度条；显示"沙盒模式 · 无胜利条件"小标。无计分、不弹通关。 | 文明灭绝/生态崩溃 → **不终止**，作为世界事件记入编年史；玩家可继续观察/干预，或从残存聚落重启。 |
| **B 里程碑** | 显示进度条"城邦级 62%"（由聚落分档 村→镇→市→都市圈 推进度计算，S3 §2.1/§2.12）。 | 达成城邦/王国级 → 弹里程碑叙事卡（不强制结束，可继续）；失败事件（聚落消亡）仅作反馈，不终止。 |
| **C 自定义** | 侧栏显示玩家自设条目清单（勾选式，如"活过10代""零生态崩溃至近代"），逐项检测进度。 | 条目达成 → 播报叙事；不终止。 |

### 8.4 运行期切换

- 入口：设置 → 目标模式 → 切换（沙盒↔里程碑↔自定义）。
- **切换不影响 `WorldState`**：仅改判定层与 HUD 呈现（概念 §3.4.1 "随时可切换"）。
- UX 须明确区分"判定层（GoalMode）"与"模拟层"，避免玩家误认切换模式改变了世界（**设计提示：切换时在 HUD 显示"仅调整目标判定，世界状态不变"提示**）。

## 9. AX-2 设计侧：R3 灾害前兆安全阀（预警触发·前兆时长·信号分层）

> **本文的核心协同交付项**（art-bible §7.1 / accessibility-grade §6 标注的"AX-2 设计侧"由 design-strategist 负责）。本节约定义**预警逻辑（何时、多长、什么内容）**，美术侧仅做视觉编码冗余（已落 art-bible §6.2/§6.3）。**协同 S2 稳态区间（数据源）+ S6 涌现叙事（内容生成，待建）**。

### 9.1 预警触发时机（对齐 S2 稳态区间）

S2 生态指标与稳态区间（§2.1）是预警的数据源。三层触发：

| 触发源（S2） | 触发条件 | 对应信号层级 | 反应窗口 |
|--------------|----------|--------------|----------|
| **趋势预警** | 某生态指标连续 N 月同向恶化（如食草种群连续 3 月下降）但未入应力区 | 前兆 Foreshadow | 早于应力区，约 3–6 月可观察 |
| **应力区 Stress** | 指标 ∈ [临界下限, 下限) 或 (上限, 临界上限]（S2 §2.1） | 警告 Warning | **3–6 游戏月**（S2 `stressDurationLimit`，MVP 6 月，核心层可渐进恶化） |
| **相变区 Phase Transition** | 指标 < 临界下限 或 > 临界上限，或应力持续超限 | 危机 Crisis / 灾害事件 | 已临界，需紧急干预（S1 紧急干预 24 月冷却） |

### 9.2 前兆时长（反应窗口设计）

- **总反应窗口 ≥ 3–6 游戏月**（S2 应力区 + `stressDurationLimit`），给玩家充足决策时间（R3 攻关、S2 V3）。
- **趋势预警更早**：在指标入应力区之前即以"前兆"提示，把窗口前移。
- **连锁预警传递**：食物链某环入应力区 → 下游环在 1–2 月后预警（S2 §2.3 连锁崩溃规则）→ 形成"逐级预警链"，玩家有 3–5 月挽回（S2 §2.3）。

### 9.3 信号内容层级（前兆 → 警告 → 危机，AX-2 冗余）

每一层**同时具备 形状图标 + 文字标签 + （图形）颜色**，颜色绝不唯一通道：

```
层级① 前兆 Foreshadow（建议观察）
   图标: 朱砂惊叹三角 ⚠
   文字: "旱灾前兆 · 河谷区降雨持续偏低"
   色: 朱砂(图形)  ·  动效: 静态（或极缓脉冲）
   行为: 入右侧日志，不置顶

层级② 警告 Warning（建议反应）
   图标: 朱砂惊叹三角 ⚠（加粗边框）
   文字: "警告 · 食草种群应力区，3 月内可能崩溃"
   色: 朱砂(图形)  ·  动效: 平滑脉冲(呼吸, AX-1)
   行为: 置顶日志 + 地图标记闪烁(非硬闪) + P1 生态灯转朱砂

层级③ 危机 Crisis（紧急）
   图标: 朱砂双环惊叹 ⛔
   文字: "危机 · 文明存亡：粮储枯竭"
   色: 朱砂(图形)  ·  动效: 平滑脉冲(强, AX-1, 无硬闪)
   行为: 持续至玩家确认 + 弹出危机详情(建议紧急干预)
```

### 9.4 高速下预警强化（R14 对策）

- 20× 加速时，所有"前兆/警告"信号**置顶+加粗**，时间轴显示"⚠高速：建议减速至 1× 响应"（§4.4）。
- 预警以**游戏月**为单位呈现，加速不改变预警逻辑（S4 §6.1 TP2）；玩家可一键减速响应。

### 9.5 与 S2 / S6 的协同接口（待 S6 落地对接）

| 协同方 | 本规格提供的契约 | 状态 |
|--------|------------------|------|
| **S2 生态** | 输出：生态指标(3/5项) + 稳态区间状态(Stable/Stress/Critical) + `monthsInStress` + `warningMessage`（S2 §2.7） | 已定义，S2 GDD 已实现 |
| **S6 叙事** | 输入契约：**事件分级(正面/中性/警告/紧急) + 游戏月时间戳 + 来源实体 + templateId**（对齐架构 `SimEvent`）。S6 据此生成编年史条目与事件卡文案 | **待 S6 落地对接**：本规格定义呈现契约，S6 负责内容生成与模板匹配 |
| **美术** | 视觉编码（图标形状/文字/平滑脉冲）已落 art-bible §6.2/§6.3/§6.4 | 已落，本规格引用 |

> ⚠ **S6 协同待办（回传主理人）**：AX-2 设计侧的信号分层（§9.3）与 `SimEvent` 分级契约需 S6 在落地时消费；当前 S6 未实现，本规格先行定义下游输入，待 S6 GDD 排期对接。
