# 世界地图生成 GDD

## 1. 系统概述（System Overview）

**一句话定义**：世界地图生成系统是世界的空间基底——以真实地球地理数据（大陆/海洋/地形/海拔/气候带/生物群系）构建全球尺度世界，并提供**开局模式开关**（远古沙盒 / 当今地缘政治），所有模拟系统与真实地理咬合运行。

**设计目标**：
- 兑现用户指令「要现在的真实世界地图」——世界是玩家认识的真实地球，而非程序化虚构大陆。
- 提供**双开局模式**（远古沙盒 / 当今地缘政治）：文明从零在真实地球上自行生长（远古沙盒），或以真实国界开局（当今地缘政治）——两者由 **New Game 设置面板**（起始时代 / 起始区域 / 国界年份 / 法律传统偏好 自选）参数化派生，详见 §2.2。
- 在**全球尺度**下以 LOD 分层解决性能——MVP 对单一起始区域高精度，其余低精度，保证地球级世界可跑。
- 为 S2 提供真实生物群系空间基底、为 S3 提供真实地理约束（河流/山脉/海岸作为自然边界）、为 S9 相机提供地球尺度 LOD 联动。

**与概念文档的对齐**：
- 概念文档 v1.3.4 §4.1 / §4.2 地图决策：原"类现实世界地图 = 程序化生成大陆级地图"已改写为"真实地球地理 + 双开局模式"——本 GDD 即该决策的落地。
- 概念文档 5.1 视觉锚点：全时代统一微缩沙盘手绘风格——地图视觉语言不因文明阶段或地理模式切换而改变。
- 概念文档 R10（双模式参数化一致性，本 GDD 首攻）/ R11（军事平衡，关联 S3 军事子系统）。

## 2. 机制设计（Mechanics）

### 2.1 真实地球地理数据基底（Real-Earth Data Source）

世界不再是程序化生成的虚构大陆，而是来自**真实地理数据**：

| 数据层 | 数据源（公开/可商用） | 提供内容 |
|--------|----------------------|---------|
| 海岸线 / 陆地 / 河湖 | Natural Earth 1:10m/1:50m Physical（coastline / land / rivers / lakes） | 大陆轮廓、海洋、主要河流与湖泊 |
| 行政区划 / 城市 | Natural Earth 1:10m Cultural（countries / populated places） | 现存国界多边形、首都与主要城市（当今地缘政治模式用） |
| 高程 | ETOPO1 / NASADEM / SRTM | 海拔（米），驱动地形与坡度 |
| 气候带 | Köppen–Geiger 气候分类（WorldClim 等） | 真实气候区（热带/温带/寒带/旱区等） |
| 生物群系 | 由高程 + 纬度 + 真实气候推导 | 森林/草原/荒漠/冻原/热带雨林/群岛等 |
| 真实民族/语系分布 | **Natural Earth 1:10m Cultural（countries / populated places）** 提供空间分布 + **Ethnologue / Glottolog 语言家族分类**（简化版，≥7 主语系：汉藏/印欧/闪米特/班图/南岛/乌拉尔/尼日尔-刚果/美洲原住民等）作为语系标注；MVP 用简化版即可 | 真实民族/语系分布：按 (lat,lon,radius) 标注的民族构成与语系——**归属：S5 拥有真实数据集与空间映射**（在起始区域按 (lat,lon,radius) 生成 `RealEthnicDistribution` 种子）；**仅地缘模式（当今地缘政治）用作 S3 族群子系统初始化种子**，由 S5 在起始区域映射；S3 仅消费不生成、不持有；沙盒模式不使用 |

> **MVP 可用简化真实数据**：MVP 不要求全分辨率全球高程，可用低分辨率真实数据（如 1:50m 海岸线 + 低精度高程 + 简化气候带）保证原型可跑；核心层再提升至更高精度与更全群系。

> **MVP 可用简化真实民族数据（v1.0.2 新增）**：真实民族/语系分布数据集 MVP 可用简化版（主要语系 ≥ 7 类 + 代表性民族构成），仅在起始区域精度映射；核心层再补更细民族颗粒度。沙盒模式（远古沙盒）不消费此数据集——民族由 S3 自主涌现分化（见 §4.2）。

**投影与网格**：采用等距圆柱投影（equirectangular，plate carrée），经纬度直接映射为网格 `WorldTile[latIdx][lonIdx]`，便于 S2 生态与 S3 文明的经纬度定位。

### 2.2 开局模式开关（Start Mode Switch）— 由 New Game 设置面板参数化

> **v1.0.1 修订**：以下四项**不再硬编码默认**，全部参数化到 New Game 设置面板，玩家开局自选；MVP 原型首跑保留「建议默认值」便于快速开局，但四项均为可改参数（详见 §2.2.1）。

两种开局模式（远古沙盒 / 当今地缘政治）仍保留为概念层模式，但其取值**由 New Game 设置面板的四项参数派生**，不再写死：

```
enum StartMode { PrimordialSandbox, ModernGeopolitics }

struct WorldInitConfig {
    // —— New Game 设置面板（玩家自选；MVP 给建议默认值，均可改）——
    Era         startEra;          // 起始时代：Primordial(远古沙盒) / EarlyModern(近代) / Modern(现代)，玩家自选
    Vector2     startRegionCenter; // 高精度起始区域中心（经纬度）——玩家自由框选真实地理区块
    float       startRegionRadius; // 高精度起始区域半径（度）
    string      startRegionPreset; // 推荐预设标签（仅 UI 提示，不锁定）："两河/新月沃地" | "黄河长江" | "尼罗河" | "地中海/欧洲" | "印度河-恒河" | "中美洲" | "自定义"
    int         borderYear;        // 国界年份（仅 useRealBorders=true 时生效）：2026=现状 / 历史年份(如1914,1945) / 自定义，玩家自选

    // —— 派生 / 内部字段 ——
    bool        useRealBorders;    // = (startEra != Primordial)；决定 GeoPoliticalInit 取哪一年国界快照
    StartMode   mode;              // 由 (startEra, useRealBorders) 派生
    string      geoDataBuild;      // 数据版本（如 "Natural Earth 1:50m"）
    RealEthnicDistribution? ethnicSeed; // = (mode == ModernGeopolitics) 时按起始区域 (startRegionCenter+Radius) 映射的真实民族/语系分布；沙盒模式为 null（民族由 S3 涌现）。结构见 S3 v1.3.2 §2.11.1
    LegalFamily? legalTraditionSeed;   // = (mode == ModernGeopolitics) 时按起始区域映射的典型法系家族（欧洲→大陆/英美、前苏东→社会主义、部落区域→习惯法）；沙盒模式为 null（家族由 S3 涌现）。枚举见 S3 v1.3.2 §2.9.1
}
}
```

#### 2.2.1 New Game 设置面板（四个可配置项，均为参数、可被玩家改）

| # | 可配置项 | 选项 / 取值 | 建议默认值（MVP 原型首跑） | 说明 |
|---|---------|------------|---------------------------|------|
| ① 起始时代 | `startEra` | 远古沙盒（Primordial）/ 近代（EarlyModern）/ 现代（Modern） | 现代（Modern） | 决定世界从哪个时代起步，不再硬编码为现代；选「远古沙盒」则无真实国界、文明从零生长；选「近代/现代」则启用真实国界 |
| ② 起始区域 | `startRegionCenter` + `startRegionRadius`（附推荐预设） | 玩家自由框选任意真实地理区块；推荐预设：两河/新月沃地、黄河长江、尼罗河、地中海/欧洲、印度河-恒河、中美洲 | 两河/新月沃地（仅预设推荐，玩家可改） | MVP 高精度起始区域即落在此区块；**不锁定**，玩家可选任意经纬度区块 |
| ③ 国界年份 | `borderYear`（仅 `useRealBorders=true` 时生效） | 现状 2026 / 历史年份（如 1914、1945）/ 玩家自定义年份 | 2026（现状） | 「当今地缘政治」模式用哪一年的真实国界，不再硬编码 2026 |
| ④ 法律传统偏好 | `legalTraditionSeed` 偏置（仅 `mode == ModernGeopolitics` 生效） | 大陆法系 / 英美法系 / 社会主义法系 / 习惯法 / 由起始区域自动映射（默认） | 由起始区域自动映射 | 地缘模式按起始区域映射典型法系家族作为 S3 `lawFamily` 初始种子；玩家可偏置但**绝不为单个国家指定家族**，沙盒模式为空（家族由 S3 涌现） |

> MVP 原型首跑可用上表「建议默认值」快速开局；四项均为参数，玩家 New Game 时可自由改。R10（双模式参数化一致性）不因参数化而破坏——无论选何参数，S3 都经同一 `IWorldGeography` 入口读地理（见 §4.2）。

> **面板第 ⑤ 项归属声明（v1.0.6 新增）**：New Game 设置面板在 UI 上还有第 ⑤ 项「**目标模式**」（沙盒·无胜利条件（默认）/ 里程碑·城邦或王国级 / 自定义目标），其定义与判定归**概念文档 §3.4.1** 与 S8 UI 所有，**不属于地理参数、不进入 `WorldInitConfig`**——S5 不读、不写、不因其改变任何地图生成行为。此处仅作跨文档一致性说明，避免"面板到底几项"的口径分歧：**地理参数 4 项（本表）+ 玩法目标 1 项（概念 §3.4.1）= 面板共 5 项**。

| 模式 | 中文名 | 地理基底 | 文明初始化 | 时代起点（= startEra，玩家自选） | 说明 |
|------|--------|---------|-----------|-------------------------------|------|
| `PrimordialSandbox` | 远古沙盒 | 真实地球（无现代国界） | S3 在真实宜居带（大河河谷/沿海平原）初始化空聚落，从零生长 | Primordial（远古）— 当 `startEra=远古沙盒` | 文明在真实地球上自行演进到现代 |
| `ModernGeopolitics` | 当今地缘政治 | 真实地球 + **所选年份**国界 + 主要城市 | S3 以真实国家开局：NationState / ModernRepublic 形态、真实领土多边形、城市作为初始聚落 | EarlyModern（近代）/ Modern（现代）— 由 `startEra` 选定 | 以所选年份的真实地球开局，战争/外交在真实国界上发生 |

**双模式共享同一空间基底**：两种模式都跑在同一份真实地球 `WorldTile` 网格上，差异仅在「谁被初始化」「时代起点 `startEra`」与「国界年份 `borderYear`」——S3 读取地理的方式完全一致（见 §4.2），参数化只改初始化内容、不改地理机制。这保证了 R10（双模式参数化一致性）的结构基础。

**民族初始化（v1.0.2 新增）**：`WorldInitConfig.ethnicSeed` 由模式派生——
- **地缘模式（当今地缘政治）**：`mode == ModernGeopolitics` 时，S5 按起始区域 `startRegionCenter + startRegionRadius` 在「真实民族/语系分布数据集」（§2.1）中映射该区域的真实民族构成，生成 `RealEthnicDistribution` 作为 `ethnicSeed`，随 `WorldInitConfig` 一并交付 S3；若起始区域跨多民族带（如巴尔干/中东），则映射出较高 `fractionalization` 的多族群种子。
- **沙盒模式（远古沙盒）**：`mode == PrimordialSandbox` 时 `ethnicSeed = null`——S5 **不提供**任何民族种子，民族由 S3 族群子系统（v1.3.2 §2.11）从单一游群自主涌现分化。两模式仅差异在初始化源，族群机制本身一致，保证 R12 行为一致。

**法律传统初始化（v1.0.3 新增）**：`WorldInitConfig.legalTraditionSeed` 由模式派生——S5 与 `ethnicSeed` 共用同一「按起始区域映射」机制，但映射对象为真实/历史法律传统（典型家族按地理带分布），交付 S3 法律家族子系统（v1.3.2 §2.9.1）作为地缘模式的 `lawFamily` 初始种子。
- **地缘模式（当今地缘政治）**：`mode == ModernGeopolitics` 时，S5 按起始区域 `startRegionCenter + startRegionRadius` 在真实/历史法律传统分布中映射该区域的典型法系家族（欧洲→大陆/英美、前苏东→社会主义、部落区域→习惯法），生成 `LegalFamily` 作为 `legalTraditionSeed`，随 `WorldInitConfig` 一并交付 S3；New Game 可选"法律传统偏好"偏置该映射，但**绝不为单个国家指定家族**。
- **沙盒模式（远古沙盒）**：`mode == PrimordialSandbox` 时 `legalTraditionSeed = null`——S5 **不提供**任何法律传统种子，家族由 S3 法律子系统（v1.3.2 §2.9.1）从政治形态/文化中自主涌现并在近代+民族国家后锁定。两模式仅差异在初始化源，法律家族机制本身一致。

#### 2.2.2 起始区域预设表（高精度起始区域建议值）

下表提供 6 个真实地理区块的高精度起始区域预设——`(lat, lon)` 为区域中心、`radius°` 为建议半径；玩家 New Game 仍可**自由框选任意区块**（不锁定），下表仅作推荐落点。地缘模式下，`ethnicSeed` / `legalTraditionSeed` 即由下表预设经 S5 空间映射（`(lat, lon, radius)` → `RealEthnicDistribution` / `LegalFamily`）生成，交付 S3 初始化族群 / 法律家族子系统。

| 预设名 | 中心(lat,lon) | 半径(°) | 典型民族/语系种子 | 法系默认(地缘模式) | 说明 |
|--------|--------------|---------|-------------------|--------------------|------|
| 两河/新月沃地 | (33.0, 44.0) | 8 | 闪米特语系（阿卡德/巴比伦/亚述/腓尼基）、苏美尔语系（孤立） | CustomaryLaw | 大河河谷文明摇篮；多民族层叠，苏美尔为孤立语系 |

### 2.3 全球尺度与 LOD 分层（Global Scale & LOD）

世界为整颗地球（全球尺度）。受性能约束，按与「高精度起始区域 / 相机焦点」的距离做 LOD 分层：

```
enum LODLevel { High, Mid, Low }

// LOD 选择（每月或相机移动时重算）
LODLevel SelectLOD(Vector2 tilePos, Vector2 focus, Vector2 startCenter) {
    if (distance(tilePos, startCenter) <= startRegionRadius) return High;  // 起始区域：高精度
    if (distance(tilePos, focus)      <= MID_RADIUS)        return Mid;   // 相机附近：中精度
    return Low;                                                          // 其余地球：低精度
}
```

| LOD | 精度 | 生态/S3 处理 |
|-----|------|--------------|
| High | 起始区域：逐 tile 高精度（真实高程/气候/生物群系全量） | S2 生态逐 tile 模拟；S3 聚落可逐 tile 选址 |
| Mid | 相机附近：区域级聚合 | S2 区域级简化；S3 聚落级 |
| Low | 其余地球：大陆级 | S2 仅保留生物群系与生态应力代理；S3 仅国家/文明级聚合（当今地缘政治模式便于远域国家渲染） |

### 2.4 数据模型（Data Model）

```
struct WorldTile {
    int id; int latIdx; int lonIdx;     // 网格坐标（equirectangular）
    bool isLand; BiomeType biome;       // 是否陆地 / 生物群系（来自真实数据）
    float elevation;                    // 海拔（米，真实数据）
    ClimateZone climate;                // 气候带（纬度 + 真实气候）
    float baseTemp; float baseRain;     // 基准温/雨（真实气候，S2 气候输入）
    bool hasCoast;                      // 是否沿海（S3 海军判定）
    LODLevel lod;                      // LOD 等级
}

struct GeoPoliticalInit {               // 仅当今地缘政治模式
    List<CountryInit> countries;        // 真实国界多边形 + 首都/主要城市
    List<CityInit>    cities;
}
struct CountryInit { string name; Polygon territory; GovernanceType type; List<CityInit> capitals; }
struct CityInit    { string name; Vector2 location; int population; }

struct WorldMapState {
    WorldInitConfig config;
    WorldTile[,] tiles;                 // 全球网格
    GeoPoliticalInit? geoPolities;      // 非空 = 当今地缘政治模式
}
```

### 2.5 算法 / 公式

**生物群系推导（数据驱动）**：`biome = f(elevation, latitude, climate)`——低海拔+湿热气候→热带雨林；中海拔+温带→森林；干旱+中纬→草原/荒漠；高纬/高海拔→冻原/苔原。MVP 以简化映射表实现，核心层接入真实生物群系数据。

**聚落选址可行性（供 S3 调用）**：S3 聚落必须邻近 `water` 资源节点、坡度 `elevation` 低于阈值、且 `biome` 属可居住群系——这些判定全部读取 `WorldTile` 属性，确保文明只在真实地球的宜居带上生长（与 S3 §2.1 选址约束一致）。

**自然边界（供 S3 调用）**：河流（`isLand=false` 且两侧 `isLand=true` 的 tile 链）与山脉（高 `elevation` 连续带）作为文明/国家扩张的自然障碍与边界；沿海（`hasCoast=true`）聚落解锁海军（S3 §2.10）。

## 3. 动态行为（Dynamics）

### 3.1 预期涌现行为

**D1 — 真实地理塑造文明路径（Real Geography Shapes Civ Path）**
> 大河河谷（真实地球的两河流域/黄河长江/尼罗河）提供肥沃冲积平原 → 农业文明优先在此萌发；沿海群岛文明偏航海/贸易；内陆草原文明偏游牧。真实地理使每局文明的"起点故事"与玩家认知的真实历史呼应，又因玩家干预不同而分叉（与 S3 D4 路径分叉叠加）。

**D2 — 自然边界约束扩张（Natural Borders Constrain Expansion）**
> 山脉与海洋成为文明扩张的硬边界——古代文明翻越山脉成本极高，沿海文明借海军跨水域但遭遇两栖劣势（S3 §2.10.5）。真实地理的"难走之处"自然产生文明势力范围，无需人工划定。

**D3 — 双模式的文明密度差异（Mode-Dependent Density）**
> 远古沙盒模式早期全球仅有零星聚落，文明密度低、扩张空间大；当今地缘政治模式开局即全球布满真实国家，战争/外交在既成国界上发生。同一套真实地理，两种密度，对应 S3 不同的演进与冲突节奏。

### 3.2 边界情况

| 边界情况 | 处理方式 |
|----------|---------|
| 真实数据缺口（某区域高程/气候缺失） | 以邻近 tile 插值或该纬度气候带默认值填充，标记 `lod=Low` 不追求高精度 |
| 极地投影畸变（equirectangular 在高纬横向拉伸） | 视觉上接受轻微拉伸（微缩沙盘风格本就非写实）；模拟定位仍用经纬度，不影响机制 |
| 子午线接缝（经度 ±180°） | 网格首尾相接处理，跨接缝的距离计算取较短弧 |
| 纯海洋 tile（无陆地） | 不生成聚落/生态种群，仅作为海军移动空间与气候背景 |
| 当今地缘政治模式的飞地/微小政区 | MVP 可合并/忽略人口过少的政区，避免无意义的微型国家 AI；核心层再完整支持 |
| 起始区域半径覆盖不足（玩家缩放远出高精度区） | 相机移出后该区降为 Mid/Low，回移时恢复 High；S3 聚落已落子的区域维持其数据精度 |

## 4. 系统交互（System Interactions）

### 4.1 接口契约

S5 是空间基底生产者，向其他系统输出只读地理数据；不消费其他系统的回写（除 S10 序列化）。

```
// S5 向其他系统暴露的只读地理查询接口
interface IWorldGeography {
    BiomeType GetBiome(Vector2 pos);        // S2/S3 查询生物群系
    float     GetElevation(Vector2 pos);    // S3 选址/坡度判定
    ClimateZone GetClimate(Vector2 pos);    // S2 气候输入
    bool      HasCoast(int settlementId);   // S3 海军判定
    List<Vector2> GetRivers();              // S3 自然边界
    LODLevel  GetLOD(Vector2 pos);          // S9 渲染联动
}
```

### 4.2 交互关系

| 交互系统 | 方向 | 内容 |
|----------|------|------|
| S2 生态模拟引擎 | S5 → S2 | 真实地球生物群系/地形/气候带作为 S2 的空间基底输入（S2 本就消费 biome/terrain 作为生态模拟基底，不自生成地形——本次仅替换数据来源，**S2 接口无需改动**，见回传标注） |
| S3 文明发展系统 | S5 → S3 | 真实地理约束文明边界与扩张（河流/山脉为自然边界、沿海解锁海军、宜居带决定聚落选址）；当今地缘政治模式的 `GeoPoliticalInit` 直接初始化 S3 的 `Polity` 与聚落；`WorldInitConfig.ethnicSeed`（仅地缘模式非 null）按起始区域映射真实民族构成，初始化 S3 族群子系统（v1.3.2 §2.11）—**S3 只消费不生成**（S3 不持有真实数据集，真实数据集与空间映射归 S5 所有） |
| S9 相机系统 | S5 ↔ S9 | S5 计算每个 tile 的 `LODLevel`；S9 相机缩放/平移时读取 LOD，决定渲染精度（地球尺度 LOD 联动） |
| S10 存档系统 | S10 ↔ S5 | 序列化 `WorldMapState`（全球网格体量大，采用分层/增量存储） |

> **真实数据集归属（v1.0.5 明确）**：真实民族/语系数据集及其空间映射（在起始区域按 `(lat, lon, radius)` 生成 `RealEthnicDistribution` / `LegalFamily` 种子）**由 S5 拥有**；S3 仅消费 `WorldInitConfig.ethnicSeed` / `legalTraditionSeed` 初始化对应子系统，**不持有真实数据集、不生成**（见 S3 §2.11.1 归属声明）。两系统仅差异在初始化的数据来源，族群 / 法律机制本身一致。

> **与 S2 的耦合说明**：S2 生态模拟引擎的输入是 biome/terrain/climate（见 S2 §2.2/§2.6），其本身不生成地形——地形来自外部基底。S5 把"程序化地形"替换为"真实地球地形"，S2 只是换了一份数据来源，注册参数与稳态区间机制不变。**无需修改 S2 GDD**（若实现时发现 S2 需在初始化时显式接收外部 biome 定义而非默认可选，仅在回传中标注，本次不擅改 S2）。
