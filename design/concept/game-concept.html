WorldSim 游戏概念文档

文档说明：本文档将已收敛的概念 DNA 转化为正式的结构化概念文档，作为后续 GDD（Game Design Document）阶段、美术圣经与技术架构的基准输入。所有设计决策均标注理由，待用户审批后定稿。

1. 概念一句话（Logline）

在一个从远古洪荒到现代都市不断演进的拟真世界中，玩家作为俯瞰全局的世界之主，通过调配生态资源、引导文明兴衰、在残酷自然中抉择存续之道，亲历一个完整世界自生自灭的涌现史诗。

解构：

要素 内容
设定 从远古到现代不断演进的拟真世界，涵盖个体生命周期、社会结构、地理生态、时间尺度四层完整性
角色 世界之主——俯瞰全局的调度者，不亲自下场操控个体
核心动作 调配生态资源 + 引导文明兴衰 + 在残酷自然中抉择存续之道
目标/体验 亲历一个完整世界自生自灭的涌现史诗——非预设叙事，而是每次都不同的文明编年

2. 设计支柱（Design Pillars）

三支柱不是三个并列的独立系统，而是一套咬合的齿轮——玩家的每一次干预同时触及三根支柱，剥离任何一根都会使核心循环断裂。以下逐根定义。

2.1 支柱一：经营建设

一句话定义：玩家通过间接引导，推动文明从原始聚落发展为城邦乃至文明体，在建设与管理的权衡中赋予世界以秩序。

该支柱回答的核心问题："在这个残酷的世界里，文明凭什么能活下来、还能活得更好？"

动词（Verbs）： - 规划（Plan）— 选址、布局聚落与功能区 - 调配（Allocate）— 在食物、材料、人口、知识之间做资源分配 - 引导（Guide）— 通过神谕/天命影响文明的发展方向（发展农业 vs. 发展狩猎） - 抉择（Decide）— 在复杂因果中判断干预何处、何时放手任自然演化

与另两根支柱的咬合关系： - × 生存对抗：经营建设是玩家应对生存压力的主要手段——不是因为"好玩"才建设，而是因为不建设文明就活不过下一个冬天。建设的每一项决策都受制于当前生存威胁（旱季该优先修水利还是筑围墙？）。 - × 生态/演化：文明建设消耗生态资源（伐木减少森林、开垦改变地貌、狩猎压低种群），同时文明也依赖生态产出（渔猎、采集、农业依赖土壤肥力与水系）。建设过度则生态崩塌，建设不足则无法抵御灾害。玩家在"发展"与"保育"之间走钢丝。

参考游戏： - Anno 系列 — 参考：供应链式经济建设、资源流转的可视化呈现、聚落从无到有的成长反馈感。不照搬其重经营轻生存的倾向。 - 文明系列（Civilization） — 参考：科技树驱动文明演进、时代推进的里程碑感。不照搬其回合制 4X 竞争框架——本作没有对手文明（至少 MVP 层没有）。

2.2 支柱二：生存对抗

一句话定义：世界是残酷的——季节更替、灾害频发、资源稀缺、物种威胁——玩家必须在文明的存续与自然的力量之间持续博弈。

该支柱回答的核心问题："这个世界为什么需要世界之主？如果没有玩家，文明会怎样？"

动词（Verbs）： - 预判（Anticipate）— 读季节趋势、灾害前兆、种群动态 - 抵御（Withstand）— 在灾害降临时调配资源保住文明命脉 - 取舍（Sacrifice）— 在不可能全部保全时，选择放弃什么以保住什么 - 适应（Adapt）— 当环境不可逆改变时，引导文明转型（如气候变冷后从农耕转渔猎）

与另两根支柱的咬合关系： - × 经营建设：生存压力是建设的动机源——没有威胁，建设就失去了紧迫感和意义。反过来，建设成果（粮储、城墙、水利）决定文明能扛住多大程度的灾害。两者构成"威胁→应对→建设→新威胁"的张力循环。 - × 生态/演化：生存威胁的来源就是生态系统本身——旱灾来自气候系统，兽患来自食肉动物种群爆发，疫病来自密集聚落与卫生条件。玩家不能"消灭"威胁源（否则世界就死了），只能学会与生态共存。生存压力也是驱动物种演化的引擎——被猎杀的食草动物进化出更快的奔跑速度，被旱灾反复打击的文明可能发展出耐旱作物。

参考游戏： - RimWorld — 参考：环境威胁驱动的叙事生成器（ raids、infestations、mental breaks ），个体在极端条件下的涌现故事。不照搬其殖民地管理微观操作——本作玩家不下场操控个体。 - Frostpunk — 参考：极端环境下"保住文明命脉"的紧迫感与道德困境（保多少、弃多少）。不照搬其线性叙事与固定场景——本作的灾害是涌现的、非脚本化的。

文明间战争（v1.3.0 新增）：当世界存在多个文明时，「生存对抗」从「文明 vs 自然」扩展到「文明 vs 文明」——战争是文明间对抗性张力的表达，由文明 AI 自主开战、在地图上自动结算并演示，玩家经干预系统间接引导军备方向而非直接指挥（详见 S3 §2.10、S1 §2.2.5）。这使「生存对抗」在文明尺度上获得对手，且不违背「不下场」原则。

2.3 支柱三：生态/演化

一句话定义：世界拥有自运转的生命系统——物种繁衍、食物链博弈、地貌演变、四季轮转——玩家既是生态的塑造者也是生态的受制者。

该支柱回答的核心问题："这个世界是活的吗？玩家走后它还在运转吗？"

动词（Verbs）： - 塑造（Shape）— 调节气候、投放或迁移物种、改变水系 - 观察（Observe）— 监测种群动态、食物链健康、生态平衡指标 - 调控（Tune）— 在生态失衡的早期信号出现时微调，避免连锁崩溃 - 敬畏（Respect）— 承认生态系统的复杂性，接受干预的不可完全预测后果

与另两根支柱的咬合关系： - × 经营建设：生态是文明建设的物质基底——土壤肥力决定农业产出，森林存量决定建筑材料，水系分布决定聚落选址。玩家在建设时不可避免地重塑生态，而重塑后的生态反过来重新约束建设空间。 - × 生存对抗：生态系统是生存威胁的发生器，也是生存资源的提供者。同一片森林既是木材来源（建设），也是野兽栖息地（生存威胁），还是水土保持者（生态功能）。三者在同一片森林上叠加，使每次"伐不伐木"的决策都成为三支柱交汇点。

参考游戏： - Dwarf Fortress — 参考：深度系统模拟、涌现式生态与经济、"故事自己发生"的设计哲学。不照搬其极端的信息密度与 ASCII 视觉——本作需要让模拟结果以可读的视觉方式呈现。 - Spore — 参考：物种演化概念、从微观到宏观的尺度跃迁感。不照搬其阶段式割裂——本作的演化是连续的、与文明交织的。

                  消耗/依赖   │     │  受制于

                    │  残酷世界 · 存续博弈 │
                    └─────────────────────┘

咬合的核心机制：玩家只有一种行动模式——干预（Intervention），而每一次干预必然同时波及三根支柱。举例：

玩家干预 经营建设影响 生存对抗影响 生态/演化影响
在旱季向河流上游降雨 农田获救，粮储保住 避免饥荒，文明免于崩溃 下游湿地生态恢复，鱼类回升
引导聚落发展农业 人口增长，定居化 食物稳定性提升，抗灾力增强 森林被开垦，野生物种栖息缩减
向森林投放一群狼 无直接影响（短期） 畜牧受威胁，猎人有了目标 食草动物种群被压制，植被恢复

设计红线：如果某个玩家行动只影响一根支柱而不触及另外两根，该行动的设计是有问题的——它把游戏拆成了三个独立小游戏。后续 GDD 阶段需以此标准审查每个干预手段。

3. MDA 分析（Mechanics-Dynamics-Aesthetics）

MDA 框架（Hunicke, LeBlanc, Zubek 2004）从设计师视角的 Mechanics（机制）出发，经由运行时涌现的 Dynamics（动态），最终抵达玩家体验端的 Aesthetics（美学/情感）。以下拆解三支柱如何收敛成单一核心循环。

3.1 Mechanics（机制层 — 设计师视角的规则与数据）

3.1.1 干预系统（Intervention System）— 玩家唯一行动接口

玩家不直接操控任何个体或单位。玩家的所有行动都通过"神谕/天命"机制实现，本质是对世界参数的间接调节：

干预类型 机制描述 作用域
气候调节 修改区域降雨量、温度偏移值 地理区域级
资源投放 在指定位置生成资源节点（水源、矿脉、可种植土地） 局部点级
物种迁移 引导物种群从A区域迁移至B区域 区域间级
灾厄/恩赐 施加灾害（旱灾、兽患、疫病）或恩赐（丰收、发现、灵感） 区域/文明级
文明引导 向聚落注入发展倾向（农业倾向、狩猎倾向、防御倾向），影响其 AI 决策权重 聚落级

干预无限制（Unlimited Intervention）：玩家的干预次数不受任何点数或配额限制——可以随时、任意次地施加干预。平衡不来自人为的资源稀缺，而来自干预的自然生态后果：每次干预都会在生态系统中引发连锁反应，过度干预将触发反噬（频繁降雨→洪涝→疫病，过度投放资源→生态失衡→种群爆发）。玩家通过经验学会"有所为有所不为"，而非被系统强制取舍。这是"不下场"设计的自然保障——你拥有无限的权力，但你面对的是一个比你更复杂的系统。

3.1.2 生态模拟引擎（Ecology Simulation Engine）

机制 描述
种群动态 每个物种有种群数量、出生率、死亡率、迁徙倾向；受食物可得性、捕食压力、气候适宜度驱动
食物链 植物 → 食草动物 → 食肉动物的三级（MVP）至多级（核心层）链式关系；任一环崩塌引发连锁
资源再生 可再生资源（森林、渔场）有再生速率；过采则枯竭，休养则恢复
地貌演变 河流改道、森林扩张/退缩、荒漠化/绿洲化——缓慢但不可逆的地表变迁
四季系统 温度、降雨、日照的周期性变化，驱动物种迁徙、作物生长周期、灾害窗口

3.1.3 文明发展系统（Civilization System）

机制 描述
聚落成长 人口增长、功能区扩展（居住/生产/仓储/防御），受食物、材料、空间约束
经济系统 生产—消耗—储备的资源循环； surplus（盈余）驱动分工与阶层分化
科技树 知识积累解锁新技术（农业→灌溉→水利→…），技术改变文明与生态的交互方式
政治结构 随聚落规模出现首领→长老会→……的治理结构演变，影响决策效率与稳定度
个体生命周期 每个 NPC 有出生→成长→衰老→死亡的生命曲线，以及关系、记忆、情感状态
族群/种族 文明的人口由民族构成——当今地缘政治模式以真实民族/语系分布（汉藏/印欧/闪米特/班图/南岛等）作种子，远古沙盒模式由游群分裂迁徙涌现分化；不同国家有不同民族构成、语言家族与族群不平等
文化家族 每个文明有独立文化签名（语言家族/审美传统/社会结构取向/核心价值轴），由环境/经济/宗教/族群共同塑造，不同国家文化明显不同
经济/社会制度谱 各国在九政治形态 + 法律之外，另有劳动制（奴隶/农奴/自由民）、经济形态（计划/市场/混合/朝贡）、行政传统（官僚/世袭/咨询）等差异化维度

3.1.4 时间推进系统（Time Progression）

机制 描述
连续时间推进 时间跑在连续实时时钟上，可暂停、可 1×/2×/5×/20× 加速；玩家无"回合"概念，世界自运转。底层为性能保留固定步长月级结算（accumulator：每累计 1 游戏月执行一次结算 pass，即原 monthly tick 的全部内容），但该步长与玩家回合解耦。季节/年份/时代由累计游戏时间推算（每 3 游戏月=1 季、12=1 年）
四季划分 春季 = 第 1–3 游戏月，夏季 = 4–6，秋季 = 7–9，冬季 = 10–12（每累计 3 游戏月切换）。季节驱动温度、降雨、作物生长周期与灾害窗口
时间尺度跃迁 从个体级（天/周）到聚落级（月/年）到国家/文明级（聚合统计）到世代级（十年/百年）的尺度切换（LOD），不同尺度下模拟精度不同——国家层仅做聚合统计，不逐个模拟国民
世代传承 个体在连续时间中成长、衰老（ageMonths 递增），死亡后其知识、财产、社会关系由后代继承；文明级"世代"由关键人物更替或制度惯性定义，文明记忆以编年史形式累积

3.2 Dynamics（动态层 — 运行时涌现行为）

机制在运行时如何交互，产生设计师无法完全预设的涌现行为：

D1 — 干预涟漪（Intervention Ripple）

玩家向上游降雨 → 下游水量增加 → 鱼群繁殖 → 渔获上升 → 聚落食物盈余 → 人口增长 → 伐木扩建 → 森林缩减 → 水土流失 → 河流含沙量上升 → 下游渔场退化……一条干预的因果链可能跨越数月才显现末端后果，且中间分叉不可预测。

D2 — 生存压力螺旋（Survival Pressure Spiral）

旱季持续 → 粮食减产 → 粮储消耗 → 人口饥饿 → 劳动力下降 → 生产力衰退 → 粮食进一步减产……如果不加干预，文明可能陷入死亡螺旋。这是"生存对抗"支柱的动力学核心——不是单次灾害，而是连锁崩溃。

D3 — 生态稳态与相变（Ecological Homeostasis & Phase Transition）

生态系统在正常区间内自我调节（食肉动物多了→食草动物少→食肉动物饿死→食草动物恢复）。但当外力（玩家干预或灾害）将系统推过临界点时，发生相变——森林不可逆地变为荒漠，或湖泊永久干涸。玩家会学到"生态是有极限的"。

D4 — 文明路径分叉（Civilization Path Divergence）

同样的初始条件，因为玩家干预倾向不同（重农 vs. 重猎 vs. 重商），文明走上截然不同的发展路径，产生不同的社会结构、技术树分支与文化特质。每局的世界都是独特的。

D5 — 世代记忆累积（Generational Memory Accumulation）

每一代 NPC 继承前人的知识与关系网，但也继承创伤与仇恨。一场三代前的兽患可能仍影响某家族对森林的态度。这种"历史惯性"使世界拥有纵深，而非每次重置。

D6 — 叙事涌现（Emergent Narrative）

以上所有 Dynamics 的交织，自发产生故事——不是预设剧本，而是从系统状态中"读"出来的叙事：某位猎人在旱季独自进山寻粮再未归来；某个聚落因三代人的水利建设终于扛过了百年一遇的大旱。玩家不是在读故事，而是在见证故事。

3.3 Aesthetics（美学层 — 玩家情感体验）

使用 Hunicke 的 8 种美学类型（Sensation / Fantasy / Narrative / Challenge / Fellowship / Discovery / Expression / Submission）标注：

主要美学（Primary Aesthetics）— 本作的核心情感目标

A1. Narrative（叙事）— 涌现史诗的悲怆与壮阔

看着一个文明从几个原始聚落发展为城邦联盟、又在一场持续三年的旱灾中崩溃——这种体验不是预设剧本给的情感冲击，而是玩家自己的决策因果在时间中展开后的回响。每局都是一部独特的文明编年史。

A2. Discovery（发现）— 因果链条的好奇与惊讶

"如果我这次不在河流上游投放鹿群，下游的渔村会不会因此消亡？"——探索干预的远期后果，追踪一条因果链穿过数月后的末端效应，带来的智力满足与意外惊喜。世界是一台可拆解的因果机器，玩家永远在追问"如果……会怎样"。

A3. Submission（沉浸/臣服）— 世界之主的庄严与渺小

作为世界之主俯瞰众生兴衰的庄严感——与"你能干预潮汐，但无法阻止一滴水蒸发"的渺小感交织。你拥有神的力量，但你面对的是一个比你更复杂的系统。这不是全能的爽快感，而是"有所为有所不为"的深沉沉浸。

A4. Expression（表达）— 塑造独特世界的创造欲

通过不同的干预策略塑造出形态各异的世界——有的世界是田园牧歌的农耕文明，有的世界是尚武的狩猎部落，有的世界因过度开发而生态凋敝。每个世界都是玩家的签名，是玩家意志在时间中的铭刻。

次要美学（Secondary Aesthetics）— 辅助情感色彩

A5. Challenge（挑战）— 在残酷世界中存续的智力博弈

在不可能全部保全时选择"放弃什么以保住什么"的道德困境与策略挑战。不是数值挑战（刷高分），而是决策挑战（做艰难选择）。

A6. Fantasy（幻想）— 克制的神明权力幻想

扮演世界之主的权力感，但被"后果不可完全预测"和"过度干预引发反噬"两个约束所克制。是"敬畏式的权力感"而非"爽快式的权力感"。

设计说明：Sensation（感官刺激）和 Fellowship（社交归属）在本作中不是主要目标——本作不是动作游戏也不依赖多人社交。但个体生命周期中的关系与情感可为 Fellowship 提供微量色彩（某个 NPC 一生寻回失散的亲人），作为叙事涌现的素材。

3.4.1 目标模式（GoalMode）— v1.4.1 新增

设计立场：WorldSim 的核心体验是"俯瞰一个活的世界"，强制胜利条件与这个定位天然冲突。因此目标性不写死在系统里，而是作为 New Game 的第 ⑤ 项参数交给玩家自选（前四项见 §4.1：起始时代 / 起始区域 / 国界年份 / 法律传统偏好）。

目标模式 胜利条件 失败事件如何处理 适合谁
A · 沙盒（Sandbox）— 默认 无。完全没有胜利条件，不计分、不弹通关、不排名 文明灭绝/生态崩溃后游戏不结束——世界继续演化（废墟、生态自然恢复、其他文明兴起），玩家可继续观察与干预，也可从残存聚落重启文明 想纯粹观察与经营世界、把"世界之主"当长期养成的玩家
B · 里程碑（Milestone） 发展至城邦或王国级（MVP 基准里程碑；核心层扩展为帝国级/跨时代里程碑序列） 构成一次目标失败判定，但仍不强制退出——提示失败后可选择"继续以沙盒方式旁观" 想要明确短期目标与成就反馈的玩家
C · 自定义目标（Custom） 玩家自设条目（如"让文明活过 10 代"/"建立城邦联盟"/"零生态崩溃达成近代"），系统仅做条件达成检测与叙事播报 同 B 想自己定规则、做挑战跑的玩家

共同规则： - 三种模式的模拟逻辑完全相同——目标模式只影响判定与 UI 呈现，绝不改变生态/文明/时间任何一条模拟规则（避免"沙盒模式变简单"这类隐形差异）。 - 达成不等于结束：里程碑达成或自定义目标完成后，只播报里程碑叙事（S6 编年史留痕），玩家可选择继续推进——延续 §R8「失败不是终点」的同款立场：成功也不是终点。 - 随时可切换：游戏中可在设置里切换目标模式（沙盒 ↔ 里程碑），不影响存档与世界状态。 - 所有模式下"文明灭绝/生态不可逆崩溃"都会作为世界事件被记录进编年史，这是叙事资产而非惩罚。

4. 范围分层（Scope Layering）

AAA 级体量不可能一次性做完。以下四层从内到外递进，每层标注覆盖"完整四层"（个体生命周期 / 社会结构 / 地理生态 / 时间尺度）中的哪几层，以及该层验证的设计假设。

4.1 MVP 层 — 最小可玩原型

目标：验证核心循环——"干预 → 生态响应 → 文明存亡"的三角咬合是否成立、玩家是否感到"我在影响一个活的世界"。

维度 MVP 范围 覆盖完整四层
地形 真实地球地理 + 双开局模式（由 New Game 设置面板参数化）：以真实地球地理数据（Natural Earth / GeoJSON 海岸线+高程+气候）为空间基底，全球尺度；New Game 时玩家在设置面板自选四项参数——① 起始时代（远古沙盒/近代/现代）② 起始区域（玩家自由框选真实地理区块，推荐预设两河/新月沃地、黄河长江、尼罗河、地中海/欧洲、印度河-恒河、中美洲但不锁定）③ 国界年份（现状 2026/历史年份/自定义，仅当今地缘政治模式）④ 法律传统偏好（大陆法系/英美法系/社会主义法系/习惯法/由起始区域自动映射，仅地缘模式生效，绝不指定某国家族）⑤ 目标模式（沙盒·无胜利条件（默认）/里程碑·城邦或王国级/自定义目标，见 §3.4.1）；双开局模式——远古沙盒（真实地球上文明从零演进）/ 当今地缘政治（以所选年份真实国界与城市开局）；MVP 对单一起始区域高精度、其余低精度 LOD；全时代统一微缩沙盘手绘视觉 地理生态 ✅ 基础完整

胜负 由玩家自选目标模式（§3.4.1）：默认 A 沙盒（无胜利条件，失败事件不终止游戏）；可选 B 里程碑——在连续时间中存活并发展至城邦或王国级（约等价于原"活过 24 个月"的文明存续目标）；或 C 自定义目标。聚落消亡在里程碑/自定义模式下作为验证失败反馈，在沙盒模式下仅作为世界事件记入编年史 —

MVP 验证的设计假设： 1. 间接控制（不操控个体）能否让玩家感到 agency（代理感）？ 2. 真实地球地理的多地貌生态是否足以产生"世界是活的"的感觉？ 3. 干预的远期后果（涟漪效应）是否可被玩家感知和追踪？ 4. 生存压力是否在"太难"与"太简单"之间存在可调的平衡空间？ 5. 模块化开关系统是否让玩家感到"自定义世界规则"的自由度？

人口尺度层级（v1.4.0 引入，与 S3 §2.1/§2.12 对齐）：本作采用真实量级——国家 = 多聚落聚合体（nation.population = Σ settlements.population），小国数百万、大国十亿级（如中华级 ~1.4B）；单聚落分档为 村 Village(~50–2,000) / 镇 Town(~2,000–20,000) / 市 City(~20,000–1,000,000) / 都市圈 Metropolis(~1,000,000–10,000,000+)，可增长至千万级，不再封顶 5 万。此前"单聚落 5 万"只是市档中段，是一个市的人口；"国家"是聚合单元，5 万只是其下辖的一个市——故 5 万远非国家的全部人口。MVP 仍从单聚落起步（默认 1 个初始聚落），其成长目标即上表"城邦或王国级"。

模块化系统设计（Modular System Toggles）：本作从架构层面采用"可开关模块"设计——世代传承、科技树、多聚落、政治结构等系统均作为独立模块实现，玩家可在开局时选择启用或关闭。MVP 阶段各模块以最简实现验证框架可行性；默认关闭以保证最小原型体量，开启后可体验对应系统的简化版。这一设计赋予玩家"自定义世界规则"的自由度，也为后续范围扩展提供即插即用的架构基础。

范围红线：MVP 的核心验证目标是"间接控制 agency 感 + 核心循环咬合"。模块化开关不等于"什么都做一点"——每个可开关模块在 MVP 阶段只实现最简骨架，不追求完整体验。地形必须为真实地球地理（玩家明确要求的核心体验，不可简化为单一地貌）。

4.2 核心层 — 1.0 版本

目标：三支柱完整运转，完整四层中三层完整 + 时间尺度的世代层，构成可发售的核心体验。

5. 视觉锚点（Visual Anchors）

以下为美术总监（林绘澄）提供的视觉方向锚点。本节定义"世界应长什么样"的方向性约束，具体美术圣经（Art Bible）由林绘澄在概念文档确认后产出。

5.1 核心视觉理念：微缩沙盘（Miniature Diorama）

本作最重要的视觉决策：美术风格全时代统一——无论文明处于远古洪荒还是现代都市，画面始终保持一致的微缩沙盘视觉语言。玩家俯瞰的是一个"桌面上活的微缩世界"，而非跟随时代切换画风。统一的视觉风格让玩家始终沉浸在同一世界的认同感中，文明演进通过建筑、技术、社会形态的内容变化来体现，而非通过画面风格的突变。

原则 说明
风格统一 全时代一套美术风格，不因文明阶段切换画面画风——时代感来自内容（建筑/技术/社会形态），不来自画风突变
微缩尺度 世界像一座可俯瞰的掌中微缩模型，有"桌面上的一盘小世界"的亲昵感与尺度感
手绘温度 低多边形 3D + 手绘纹理（Hand-Painted Texture），NPR 非写实渲染，画面有"人手做出来"的温度感
俯视可读 所有美术资源服务于俯瞰视角下的信息可读性——玩家一眼读懂地形、聚落、状态

六大风格关键词：

  1. 微缩沙盘（Diorama） — 世界像一座可俯瞰的微缩沙盘模型，有"掌中世界"的尺度感与亲昵感
  2. 手绘温度（Hand-Painted Warmth） — 手绘纹理赋予画面温度感与匠人气质，避免冷冰冰的纯 CG 感
  3. 层次分明（Layered Depth） — 地形高低、植被疏密、聚落分布形成清晰的空间纵深层级
  4. 生机盎然（Lived-in Vitality） — 世界不是空旷的模型展，而是"有人住过"的——炊烟、田垄、兽迹、水纹都在动
  5. 史诗质感（Epic Texture） — 在微缩尺度中蕴含宏大——远山如黛、长河落日，小画面中有大气象
  6. 俯视可读（Top-Down Readability） — 俯瞰视角下一切信息一目了然，美术服务于玩法可读性

视觉目标：玩家从开局到终局看到的是同一个世界的同一种画风——微缩沙盘上手绘质感的小世界。文明从茅棚到城邦到都市的演进，通过建筑形态、聚落规模、技术产物的变化来传达，画面风格本身始终如一。

5.4 关键场景视觉想象

场景一：晨雾中的河谷聚落（MVP 核心场景）

晨雾未散，一条河流蜿蜒穿过草原。河岸边，七八个茅棚聚落炊烟初升，几个小人在田间走动——他们的动作是功能性的（播种、取水、巡望），不是装饰性的。远处，几只食草动物在林缘低头吃草，一只食肉动物的影子在灌木后若隐若现。画面整体偏青绿与晨雾灰白，炊烟是唯一暖色。玩家俯瞰，如同俯瞰一座桌面上活的微缩世界。

场景二：大旱降临（生存压力可视化）

第三季无雨。河流缩成一线，露出的河床是干裂的土黄。农田颜色从绿褪为枯黄，聚落周围的树木稀疏了——伐木痕迹清晰可见。小人的移动速度变慢（饥饿 debuff 可视化），有几个小人的图标上出现了红色标记（疾病/饥饿状态）。画面整体偏黄褐，饱和度明显降低，天空是无云的苍白。玩家在这个画面中读到的不是"灾难特效"，而是"世界正在缓慢死去"的压抑。

场景三：文明鼎盛（核心层场景）

数代之后。河谷聚落已扩展为小型城邦——石木混合建筑、灌溉水渠纵横、集市上有小人在交易。远处的森林被砍伐了一半（边界清晰可见），取而代之的是农田与道路。河流上出现了渔船。画面色彩丰富但不鲜艳——土黄的建筑、青绿的农田、灰蓝的水面、远处黛色的残存山林。画面中央，一个金色光芒正在闪烁——那是玩家正在施加的一次干预。世界是活的，但也是被塑造过的。建筑更密集、更高大了，但画面的质感与色调与场景一始终一致——这是同一个世界在生长，而非换了画风。

7. 设计风险与未决问题

以下问题在概念阶段尚未解决，标注优先级供后续 GDD 阶段攻关。P0 = 阻断核心循环，必须在进入 GDD 前有方向性答案；P1 = 影响核心层质量，GDD 阶段必须解决；P2 = 影响体验细节，可延后。

P0 级（阻断核心循环）

R1. 间接控制的 agency（代理感）问题 - 问题：玩家不操控个体、只做间接干预，如何让玩家感到"是我在影响世界"而非"我在看一个自动模拟器"？ - 风险：如果玩家感到无力或无聊，核心循环就塌了——这是本作最根本的设计赌注。 - 待解方向：干预的即时视觉反馈（金色光环+涟漪）需足够强烈让玩家感到"我做了什么"；远期后果的可追踪性需让玩家建立"是我干的"因果认知（因果链追溯系统）；干预的副作用链让玩家感受到"我的每个决定都在改变世界"——agency 感不来自资源稀缺，而来自可见的因果影响力。 - 验证时机：MVP 原型阶段必须验证。

R2. 干预与涌现性的矛盾 - 问题：干预太强 → 玩家直接操纵世界，涌现性消失，变成建造游戏；干预太弱 → 玩家感到无力，变成观看模拟。 - 风险：找不到"恰到好处的间接感"的平衡点。 - 待解方向：干预无次数限制，但自然生态后果是核心制衡——每次干预都有潜在的生态连锁反应（频繁降雨→洪涝→疫病，过度投放资源→生态失衡→种群爆发）；延迟后果确保干预效果不即时可控；过度干预引发反噬让玩家通过经验学会"有所为有所不为"。平衡来自世界的复杂性而非人为配额。需大量 playtest 调参副作用强度。 - 验证时机：MVP → 核心层持续迭代。

R3. 涌现不可控性与世界崩坏 - 问题：纯涌现系统可能产生"世界自己走向毁灭"的不可逆局面——生态连锁崩溃、文明死亡螺旋——玩家感到不公平（"我没做什么它就死了"）。 - 风险：不可控的涌现会变成挫败感而非惊喜感。 - 待解方向：设计"生态稳态区间"机制——系统在正常区间内自我修复，只有被推过临界点才相变；给玩家灾害前兆的足够预警时间；提供"紧急干预"手段（有冷却限制但无点数消耗）力挽狂澜。 - 验证时机：MVP 原型阶段验证稳态机制。

P1 级（影响核心层质量）

R4. 叙事涌现的可读性 - 问题：个体故事（某猎人旱季进山未归）在宏观俯视视角下如何被玩家感知？如果只是后台日志里一行字，玩家不会产生 Narrative 美学体验。 - 待解方向：事件检测器 + 叙事呈现层——关键事件以卷轴式通知弹出；编年史可随时翻阅；关键个体（英雄/悲剧人物）给予视觉高亮。但注意不能过度打断模拟节奏。 - 验证时机：核心层阶段。

R5. 认知过载风险 - 问题：完整四层同时运转时，信息量巨大——生态指标、文明状态、个体生命、时间尺度——玩家可能被淹没。 - 风险：违反设计红线中的"认知过载"禁忌。 - 待解方向：UX 设计是关键解法——信息分层呈现（总览→详情→逐项的折叠式面板）、智能事件筛选（只推送重要事件）、可自定义的关注焦点（玩家可"关注"某个聚落/某个体，只看相关推送）。 - 验证时机：核心层阶段，需 UX 规格 GDD 配合。

R6. 时代演进的内容断裂感 - 问题：题材轴是"古代 → 现代都市"，古代文明（茅棚聚落）和现代都市（高楼城市）的系统、交互方式差异巨大——如何在统一视觉风格下通过内容变化传达时代跃迁，而不产生"换了个游戏"的断裂感？ - 待解方向：渐进式时代演进设计——每个时代不是"切换"而是"生长"出来的（农业技术累积 → 灌溉 → 水利 → 水车 → … → 工业萌芽）。视觉风格全时代统一（微缩沙盘手绘风），时代感通过建筑形态、技术产物、社会结构的变化传达，而非画风突变。远景层范围，核心层需先解决古代阶段的完整性。 - 验证时机：延展层 → 远景层。

P2 级（影响体验细节）

R7. 中文文化内核的融入深度 - 问题：产品定位是"中文世界模拟"，但"中文"不应只是美术层面的水墨风格——世界观、哲学底色、文明形态如何体现东方特质（而非披一层皮的西方中世纪模拟）？ - 待解方向：在世界观 GDD 阶段定义东方哲学底色——如"天人合一"（生态与文明不可分割的东方版表述）、"天命"（干预的文化叙事包装）、"礼"（社会结构的东方秩序观）。但需避免说教与文化符号堆砌。 - 验证时机：叙事 GDD 阶段。

R8. 难度曲线与失败体验设计 - 问题：上帝视角游戏没有传统"关卡难度"，失败（文明灭绝）的体验如何设计——是 Game Over 重来，还是"世界继续但文明已亡，玩家可以引导新文明从废墟中崛起"？ - 待解方向：倾向后者——失败不是终点而是叙事转折。文明灭绝后，世界生态仍在，残余知识散落为"遗迹"，玩家可引导新的文明在旧文明废墟上重建。这比"Game Over"更符合涌现史诗的调性。 - 验证时机：核心层阶段。

R9. 无对手文明的单人游戏长期动机 - 问题：MVP 和核心层没有对手文明（没有竞争 AI），玩家面对的只有环境与生态。长期来看，仅靠"涌现惊喜"和"自定目标"能否维持数十小时的动机？ - 待解方向：延展层引入文明间关系（多聚落/多文明的竞争与协作）作为长期动机补充；核心层靠"每局世界不同"的重玩性 + 玩家自定目标的多样性。但需在核心层 playtest 中验证"无对手是否够玩"。 - 验证时机：核心层 playtest。
