# 项目长期记忆 — 完整世界模拟游戏

## 产品定位
- 上帝视角的文明世界模拟游戏（中文）。
- 玩家 = 世界之主，俯瞰调度，不下场。
- 三支柱：经营建设 × 生存对抗 × 生态/演化。
- 题材轴：古代 → 现代都市（时代 / 文明演进）。
- "完整"四层：个体生命周期 / 社会结构 / 地理生态 / 时间尺度。
- 评审强度：Full（每阶段严格质量门 + 文档）。
- 范围 AAA 级，必须做范围分层（MVP / 核心 / 延展 / 远景）。

## 设计决策（2026-08-12）
- **模块化系统开关（Modular System Toggles）**：世代传承/科技树/多聚落/政治结构从 MVP 起即为可开关模块，玩家开局自选启用/关闭。默认关闭保最小原型，开启体验简化版。
- **真实地球地理（2026-08-12 修订·用户新指令，推翻原"程序化大陆"决策）**：地图从"程序化生成大陆级地图"pivot 为**真实地球地理数据**（Natural Earth / GeoJSON 海岸线+高程+气候为基底），全球尺度，MVP 先精算一个起始区域、其余低精度 LOD。开局**模式开关**：`远古沙盒`（真实地球上文明从零演进）/ `当今地缘政治`（以现存真实国界开局）。旧"程序化大陆级地图"决策作废。S2 生态引擎仅换输入源、未改接口。
- **军事维度（2026-08-12 新增·用户指令）**：并入 S3 文明发展系统作为**第十子系统"军事/战争"**——文明级抽象军事能力（军力/军事科技线 T1-T8/城防/海军）+ 战略层（玩家仅经 S1 注入军事方针 `devBias_military`，间接引导）+ 战争在地图自动结算；**不突破"不下场"原则**。新增风险 **R11（军事平衡）** 与 **R10（双模式一致性）**。
- **视觉风格全时代统一（2026-08-12 修订）**：取消"风格随时代演进"，改为全时代统一的**微缩沙盘手绘风格**（低多边形 + 手绘纹理 + NPR）。文明演进通过建筑形态、技术产物的内容变化传达，画面风格始终如一。简化了 shader/后处理管线（不再需要 Universal Era Shader / _EraProgress 参数 / 风格过渡机制）。
- **干预系统无点数限制（2026-08-12 修订）**：移除干预力点数系统（原 3 点/Turn、上限 6 点、紧急干预 5 点），干预改为**无限次、无配额**。平衡机制从"资源稀缺"改为"自然生态后果制衡"——过度干预触发反噬（频繁降雨→洪涝→疫病）。紧急干预保留但无点数消耗，改为 24 个月冷却。agency 感来自可见的因果影响力而非资源稀缺。
- **连续时间推进（2026-08-12 修订·用户指令"取消回合制"）**：彻底取消月历回合制（原 1 月=1 回合）。世界跑在**连续实时时钟**上（可暂停 + 1×/2×/5×/20× 加速），**无玩家回合**；玩家干预**异步生效**（仍带延迟）；底层为性能保留**固定步长月级结算 pass**（每累计 1 游戏月执行一次，驱动 S2 生态 + S3 文明结算），但与玩家回合解耦。季节/年份/时代由连续时间推算。新建 **S4 时间推进系统 GDD v1.0.0** 承载此模型（含尺度跃迁 个体/聚落/国家/世代 + 世代传承）。
- **族群 / 种族子系统（2026-08-12 新增·用户指令）**：S3 新增**第十一子系统「族群」**——地缘模式用真实民族/语系分布（汉藏/印欧/闪米特/班图/南岛等）作种子，沙盒模式由游群分裂-迁徙-隔离涌现；`EthnicGroup`/`EthnicComposition` 数据模型；与政治（民族自决合法性变体 `EthnicNationalism`，与四世俗来源并存不替代）、军事（族群极化内战动因）、文化（承载语系）、社会（族群不平等）耦合。**全部进核心层**（用户拍板，非 MVP 可关模块）。
- **跨国文化家族 + 经济/社会制度谱（2026-08-12 新增·用户指令）**：文化系统扩展为显式**跨国文化家族**（`CultureProfile`：语系/审美传统/社会结构取向/核心价值轴），各国签名独立；制度维度增**经济/社会制度谱**（劳动制 奴隶/农奴/自由民、经济 计划/市场/混合/朝贡、行政 官僚/世袭/咨询），与九政治形态共同构成分国别差异化。**全部进核心层**。
- **法律体系家族已落地（2026-08-12·用户确认"现在做"）**：`LegalFamily` 枚举（大陆/英美/社会主义/习惯法）于 S3 v1.3.1 §2.9.1 正式实现，与 `LawStage` 成熟度**正交**（同一现代国家可挂不同家族）；地缘模式按真实法律传统种子（S5 `legalTraditionSeed`）初始化、沙盒模式涌现并在近代+民族国家后锁定；坚持"无神法"——宗教法不进入合法性公式。S5 New Game 设置面板已加 ④ 法律传统偏好项（与"开局全自选"一致，仅偏置不指定）。
- **人口尺度层级 + 国家=多聚落聚合（2026-08-12 新增·用户指令）**：取消"单聚落封顶 5 万"的微缩沙盒假设。聚落分档：村(~50-2,000)/镇(~2,000-20,000)/市(~20,000-1,000,000)/都市圈(~1,000,000-10,000,000+，可续增至亿级)，**不再封顶 5 万**。国家/政体是聚合单元（`Polity`/`NationState` = 聚合 ≥1 个聚落，总人口 = Σ 聚落，真实量级 小国数百万~大国十亿级，中华级 ~1.4B）——5 万只是"市"档中段，远非国家全部人口。模拟策略：聚落层跑个体/代理微观模拟，国家层仅聚合统计（总数/产出/军力/稳定度），不逐人模拟。治理形态人口区间（§2.4.3）同步改写为政体聚合总人口。直接回应了用户"5 万人的国家能干嘛/人口为啥这么少"的质疑。
