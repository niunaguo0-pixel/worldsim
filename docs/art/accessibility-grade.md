# WorldSim 可访问性分级评估

> **对齐声明**：美术圣经已正式落盘（`design/art/art-bible.md` v1.0.0），本评估与之完全一致并引用其视觉规范（配色 §2.2/§2.3、UI §6、可访问性 §7、技术美术 §8.4、风险 A1）。评估紧扣"上帝视角俯瞰模拟"的真实交互特性，不做泛泛的通用无障碍清单。本版（v1.1.0）不再基于假想圣经——上轮 F1/F2/F3/A1 缺陷均已在 art-bible v1.0.0 中修订落地。

---

## 0. 评估范围与三档定义

**"可访问性"作为 Phase 3 技术资产的正式质量维度**：本作是中文上帝视角文明世界模拟，玩家以间接干预（光标 + 面板）调度世界，大量信息依赖地图标记、事件通知、编年史呈现。可读、可辨、可控，本身就是核心玩法——因此可访问性不是"锦上添花"，而是核心循环可达性的底座。

**三档定义（本评估内部口径，供 Phase 3 资产排期参考）**

| 档位 | 含义 | 定位 |
|------|------|------|
| **Basic（基础档）** | 每个可发布构建都必须具备的底线，多为低成本/架构预埋项 | MVP 入场券 |
| **Standard（标准档）** | 一款严肃 PC 模拟应有的可访问性质量 | 核心层目标线 |
| **Comprehensive（完备档）** | 示范性、可细粒度定制的无障碍体验 | 延展/远景层 |

**与项目既有范围分层对齐**：MVP / 核心层 / 延展层 / 远景层（见 `systems-index.md` §5 与概念文档 §4.4）。本评估第 4 节"特性矩阵"对每个特性标注计划落地档位。

## 1. 上帝视角俯瞰模拟的可访问性特异性

本作与动作/射击类游戏的可访问性诉求不同，关键特异性如下，后续分项评估均以此为锚：

1. **玩家是"观察者/调度者"，不是"操作者"**：无单位操控、无及时反应要求（无 QTE/无闪避）。这带来一个强项——**全键盘可玩性极高**，可访问性上限本应高于动作游戏。
2. **信息密度高、以视觉编码为主**：地形、聚落、资源、灾害、物种状态、NPC 职业全部仰赖俯视画面 + 叠加标记（美术圣经 L0–L6 七层）传达。色弱玩家一旦丢失某个颜色通道，可能直接丢失"灾害前兆"这一安全阀信息。
3. **连续时间 + 多档加速（1×/2×/5×/20×）**：高速下大量动效（NPC 移动、天气粒子、干预涟漪、季节 lerp、灾害特效、LOD 跳变）并发，存在视觉抖动/闪烁/晕动风险。
4. **文本是第二信息通道**：事件通知（右侧滑入卡）、编年史（全屏可读视图）承载叙事与状态。文本若瞬时消失或不可缩放，等于关闭了一条信息通路。
5. **统一 NPR 手绘风 + 大地色系**：温润低饱和的手绘质感天然压低对比度，叠加面板半透明——可读性已由美术圣经 §6.1（文本落 100% 不透明暖白内容卡）主动保障。

## 3. 逐项三档对照评估

### 3.1 色弱友好（Color-Weak Friendly）

**项目特性下的风险**：调色板为大地色系（土黄/赭石/青绿/岩石灰，皆为中等明度）+ 朱砂/暖金点缀。两处高风险：
- **红弱（protanopia）/ 全色弱玩家丢失朱砂红 = 丢失灾害警告与关键事件**（美术圣经 §6.2 唯一用朱砂表达"警告/紧急"，但已叠加图标+文字）。灾害前兆是 R3 安全阀——色弱玩家不能因丢失红色通道而失去安全阀。
- **绿弱（deuteranopia）玩家**难分青绿（植被/农田/农职业）与土黄/赭石，密集地图上标记易糊成一片。

**已有缓解（美术圣经已做对的事）**：地图标记用**形状编码**为主、颜色为辅（屋形/足印/圆点/惊叹符，§6.2）；NPC 令牌强制深褐描边+投影盘+职业字形（§3.3，满足 A1 明度差与 WCAG 1.4.11）；风险 A1 已含"色弱可辨"通过标准。这已符合"不单靠颜色传达意义"的 WCAG 1.4.1 原则（AX-2 已采纳 P0）。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 严格遵守"信息不单靠颜色"：所有意义通道（灾害/资源/状态）同时有形状/图标/文字冗余；朱砂警告叠加图标 + 平滑脉冲（非硬闪，AX-1）+ （音频，待 audio-director）三冗余；禁用"仅颜色区分"的临时状态 |
| **Standard（核心层）** | 在 Basic 基础上提供**色觉缺陷（CVD）模式**：① 永久强制"图标 + 文字标签"叠加；② 对易混色对（青绿↔土黄、朱砂↔赭石）做安全化重映射或加图案（pattern）；③ 危险信息增配非红色编码（如三角警示符 + 边框） |
| **Comprehensive（延展/远景）** | 细分三型模拟预览（protan/deutan/tritan）供开发者自检；CVD 模式可叠加"色相旋转 + 图案密度"双保险；地形材质引入可辨纹理（非仅靠色块） |

**计划落地档位**：Basic → MVP；Standard（CVD 模式）→ **核心层**。

### 3.2 字体缩放（Text Scaling）

**项目特性下的考量**：编年史（美术圣经 §6.3）已设计为"可搜索/筛选/缩放"的全屏视图，是良好起点。其余 UI 文本必须可缩放而不破版。关键生产约束：**绝不使用位图字体**，必须用 **SDF / TextMeshPro 矢量字体**（美术圣经 §6.1 已显式规定）。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 全部 UI 文本走 TMP/SDF 矢量字体，基准 100%；编年史内置缩放（已有）；CJK 小字号保笔画完整（避免手绘装饰体作正文） |
| **Standard（核心层）** | 全局 UI 文本缩放滑块（75%–150%，按相对单位布局，不破版）；编年史缩放与全局联动；设最小字号下限（如 ≥12px@1080p） |
| **Comprehensive（延展）** | 分面板独立缩放 + 易读字体选项（在思源黑体基础上提供更高认读性 CJK 字体）+ 行距/字距可调 |

**计划落地档位**：Basic → MVP；Standard（全局缩放滑块）→ **核心层**。

### 3.3 UI 对比度（UI Contrast under NPR）

**项目特性下的风险**：NPR 手绘风天然低对比 + 面板半透明，叠加 §2 核算的暖金/青绿文本失败（F1/F2，已修订）。面板文字主体（深褐 on 暖白 12.1:1）达标，点缀色文本已由 art-bible v1.0.0 改为非文本通道或深色主题。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 正文一律深褐 on 暖白（≥12:1）；暖金/青绿仅作填充/边框/大图形/图标，不作文本；面板 100% 不透明内容卡（已落 F3）；**F1/F2/A1 已修订** |
| **Standard（核心层）** | 提供**高对比主题**（见 3.8）；所有状态文本在两种主题下均 ≥4.5:1；动态场景下（灾害压暗/暗角/雪原）保证文本可读（实色卡兜底） |
| **Comprehensive（远景）** | 对比度随环境自适应（如暗场景下自动提亮面板底）；可逐元素微调对比 |

**计划落地档位**：Basic → MVP；Standard → **核心层**。

### 3.4 操作重映射（Input Remapping）

**项目特性下的优势**：间接干预 = 光标 + 面板点击，无操作时序压力。这意味着**全键盘可玩性极高**——本作本就应是"可纯键盘通关"的强项。输入面：鼠标移动（世界光标）、左键（选/放）、右键（取消）、面板键位、空格（暂停）、1/2/5/20（变速）、拖拽/点击时间轴。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 热键可重映射（至少变速键、暂停、干预类型切换）；鼠标 + 键盘双通道均可完成核心循环 |
| **Standard（核心层）** | 完整键盘导航（Tab/方向键遍历所有面板与控件）+ 可视化重绑定 UI + 时间轴支持"点击设值"替代拖拽；提供预设方案（如左手/右手布局） |
| **Comprehensive（延展）** | 多套键位配置档（profile）导入导出；单手/仅鼠标/仅键盘三模式官方支持；与辅助外设（开关控制）兼容的慢速扫描模式 |

**计划落地档位**：Basic → MVP；Standard（键盘导航 + 重绑定 UI）→ **核心层**。

### 3.5 字幕 / 文本可读（Subtitles & Persistent Readability）

**项目特性下的考量**：本作无角色对白，故无传统"字幕"，但**事件通知与编年史条目就是文本信息通道**，必须"持续可读、非瞬时消失"。美术圣经 §6.3 事件卡为右侧滑入（约 0.3s）——已规定**不瞬时消失**，进入可滚动、可回看的通知日志。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 事件通知**不瞬时消失**：进入可滚动、可回看的通知日志（与干预系统 §5.1「干预历史记录面板」、S6 编年史同源）；关键/紧急事件持续至玩家确认 |
| **Standard（核心层）** | 日志可搜索/筛选/按严重度排序（呼应 R5 认知过载治理）；事件提供**闭式字幕式呈现**（标题 + 简明正文 + 时间戳）；可设自动消失时长或永久驻留 |
| **Comprehensive（远景）** | 编年史/事件**音频旁述**（audio description，待 audio-director 协同）；可按系统/聚落过滤订阅 |

**计划落地档位**：Basic（持久日志）→ MVP；Standard（可检索日志 + 闭式呈现）→ **核心层**。

### 3.6 动态视觉稳定（Reduced Motion / Visual Stability）

**项目特性下的风险**：连续时间 + 20× 加速下，NPC 移动、天气粒子、干预涟漪、季节 lerp、灾害特效、LOD 跳变并发；美术圣经原 §6.4 规定紧急/危机事件用**朱砂红闪烁**——硬闪烁涉**光敏性/癫痫安全**风险（见 §6 **AX-1 已采纳 P0**）。好消息：美术圣经 §8.1 已选 FXAA/SMAA 而非 TAA，"微缩尺度下 TAA 可能导致抖动"——抖动意识已在技术美术层面就位。

| 档位 | 交付内容 |
|------|----------|
| **Basic（MVP）** | 默认不用硬闪烁表达警告（改用平滑脉冲/呼吸，仍可感知，**已落 AX-1**）；抗锯齿维持 FXAA/SMAA 而非 TAA；高速下不新增屏幕整体抖动 |
| **Standard（核心层）** | **"减少动态"总开关**（已落 art-bible §8.4）：关闭硬闪烁、平滑季节 lerp、衰减 Bloom、削弱/关闭非必要天气粒子、平滑相机与 LOD 跳变过渡；该开关经 TA 接 URP Volume 实现 |
| **Comprehensive（延展）** | 粒度化控制：天气粒子强度、季节过渡速度、干预涟漪幅度、相机移动缓动各自可调；提供"极简视觉"档（只留信息必要动效） |

**计划落地档位**：Basic → MVP；Standard（减少动态总开关）→ **核心层**。

### 3.7 色盲模式（Colorblind / CVD Mode）

见 3.1 Standard 档。独立列出以对齐任务要求：本模式是色弱友好的 Standard 级交付，核心是"形状/图案/文字三重冗余 + 易混色对安全化重映射"，而非简单滤镜。

**计划落地档位**：**核心层**（Standard）。

### 3.8 高对比主题（High-Contrast Theme）

**项目特性下的价值**：NPR 软质感压低对比，高对比主题可"绕过"手绘软度，用实色高对比面板保障可读性；同时**天然修复 F1**——暖金在深色底上 ≥6:1 可用（见 §2）。主题切换由 TA 经 URP Volume + UI 样式表实现（art-bible §8.4），不影响世界渲染。

**计划落地档位**：**核心层**（Standard）。

### 3.9 减少动态模糊 / 特效（Reduce Blur & VFX）

本作 NPR 无运动模糊、无 TAA（§8.1），动态模糊风险低。主要归口到 3.6 的"减少动态"开关（粒子/Bloom/过渡）。另：提供**粒子数量上限可调**（美术圣经 §8.3 同屏粒子预算 ≤5000，允许按设备/偏好下调，已落 §8.4），既是性能档也是晕动缓解档。

**计划落地档位**：Basic（无 TAA/无运动模糊，已满足）→ MVP；Standard（粒子上限可调）→ **核心层**（并入 3.6 减少动态）。

### 3.10 音频提示替补（Audio Cue Substitution）

视觉提示（灾害、状态变化）应有冗余音频线索，以助色弱/低视力玩家。本项目音频由 **audio-director（阮和鸣）** 负责，本评估**仅标注接口需求、不展开音频设计**：

- 需要：灾害前兆、紧急事件、关键状态变化（饥荒/疫病/NPC 死亡）的冗余音频提示（**AX-2 第三冗余通道，美术侧图标+文字已占位，音频待补**）；
- 需要：独立音量通道（环境/事件/UI），以及（若未来有旁述）字幕/字幕音量通道；
- 待 audio-director 在 `design/accessibility-requirements.md` 或音频 GDD 中补全。

**计划落地档位**：MVP 起由 audio-director 协同交付基础事件音；完整冗余音频 → 核心层。

## 7. 建议落地策略（回传主理人要点）

1. **三档起步策略（不变）**：MVP 以 **Basic** 全线兜底（架构预埋：SDF 字体、形状编码标记、持久通知日志、无 TAA、热键可重映射、无硬闪烁）；**核心层目标定为 Standard**（CVD 模式、高对比主题、减少动态总开关、全局字体缩放、完整键盘导航、可检索日志）；Comprehensive 留延展/远景。
