# WorldSim 架构自评（Architecture Review）

> 评审强度：Full。本评审判定 **PASS / CONCERNS / FAIL**，并列出阻塞项。重点评估：Gate-0 确定性可达性、MVP 范围可实现性、性能上限与确定性约束的冲突。

## 判定：CONCERNS（有条件通过，Gate-0 为关键门，阻塞项须清零后进入 Phase 4）

架构在概念上完整、与 S1–S5 GDD 对齐、确定性路径清晰。**无 FAIL 级根本缺陷**，但存在需在主理人/用户确认 ADR 选项、并跑通 Gate-0 串行路径后才能消除的 CONCERN。这些 CONCERN 不阻断"架构定稿"，但阻断"Phase 4 实装启动"。

---

## 1. Gate-0 确定性可达性 — 评估：可达（CONCERN：依赖 ADR-002 落地）

**结论：在 PC x64 单平台 + 同 Unity 版本 + 同 Burst 设置下，可达逐位一致。**

依据：
- 固定步长月级 pass（S4 §2.2）使模拟层与表现层解耦，1×/20× 只缩放 `dtGame` 不改变 pass 内容（R14 前提成立）。
- 五条铁律（S4 §7.3）已被架构逐条落地：固定步长唯一时间源、双频按边界时间戳升序合并（§3.3 修正伪代码）、稳定 ID 排序遍历（§3.5）、RNG 分流入档（§4.2）、禁不确定并发与浮点漂移（§4.5）。
- 推荐 **串行月级 pass（无 Job）** 作为 Gate-0 首跑路径（ADR-001 方案 C）→ 确定性最干净，无并行归约风险。

**CONCERN / 阻塞项**：
- B1（已解决，2026-08-12 用户采纳 ADR-002 选项 2）：**选项 2（float + 禁 fast-math + 量化写回 + `Fix` 兜底）** 已采纳，非全局定点，Gate-0 成本与风险可控。
- B2：须确认 CI 锁定"同 Unity 版本 + 同 Burst 设置"（ADR-003），否则 float 逐位一致前提失效。
- B3：须实现 `Quantize` 边界与指标哈希（**FNV-1a-64** over 确定性字节流；xxHash 未实现）并写入 CI 门禁；哈希函数本身须确定（禁 `string.GetHashCode` 非稳定序）。

> 收敛说明（2026-08-12）：ADR-001~004 已锁定，B1 随 ADR-002 选项 2 采纳而清零；本评审判定维持 **CONCERNS**，但 CONCERNS 收敛为 **B2–B4** 执行项（均列为 Phase 4 预制作入口条件，须排期）。

## 2. MVP 范围可实现性 — 评估：可实现（CONCERN：真实地球数据管线）

**结论：MVP（单聚落 + 3 干预 + 混合结算 + 连续时钟 + 真实地球基底）工程可实现。**

依据：
- 模拟核心零场景依赖，单聚落/少量物种规模下月级 pass 成本极低。
- 混合结算（§7.1）使 MVP 算力约纯月级 1.5–2×，远低于全局周级，单聚落下无压力。
- 模块化开关（S7）默认关科技/政治/宗教/文化/法律/军事/族群，MVP 仅开聚落成长/经济/个体骨架/干预/时代(最小)，范围可控。
- 真实地球数据由 S5 以简化真实数据（1:50m + 低精度高程 + 简化气候）起步，MVP 仅单区域 High，其余 Low（§7.2）。

**CONCERN / 阻塞项**：
- B4：真实地球 GeoJSON/高程/气候数据获取与导入管线（Editor 工具 + `region-presets.json` 消费）须在 Phase 4 预制作建立；属内容/工具任务，非架构缺陷，但缺它 MVP 无法跑真实地图。
- B5：`region-presets.json` 契约已对齐（中心 lat/lon、半径°、ethnicSeed、legalFamilyDefault），但须确认 S5 空间映射（preset → `RealEthnicDistribution` / `LegalFamily`）的实现口径与"绝不指定单国家族"红线在导入器落地。

## 3. 性能上限与确定性约束的冲突 — 评估：可控（CONCERN：并行化收益受限）

**结论：两者存在固有张力，但已被架构消解到可接受。**

冲突本质：
- 确定性要"串行、有序、稳定遍历"（铁律 3/5）；性能要"并行、乱序归约"。直接并行破坏重放。

架构消解手段：
- **混合结算**已把算力压到 ~1.5–2×；
- **尺度聚合**（§7.4）：国家层仅 Σ 聚落，**成本绑定聚落数而非人口数**——这是性能天花板的关键杠杆，使千万~十亿级国家不引发逐 NPC 灾难（T1/T4 响应）；
- **地理 LOD**（§7.2）：全球网格 High/Mid/Low，月 tick 预算受 Low 聚合保护（WM2）；
- **叶子并行**（回退 2）：仅同区域逐 tile 生态、逐个体 needs 等无因果耦合计算可 Job 化，且 Gate-0 通过后、固定块序归约 + 禁 fast-math + 可选 `Fix`。

**CONCERN / 阻塞项**：
- B6：核心层全开（多聚落/多国家 + 完整生态 + Job 并行）下的月级 pass 预算（目标 <50ms）须在 Phase 4 用 profiler 实测验证；若超预算，回退 2（串行化）或收紧 LOD 是既定杠杆，不阻断架构。
- B7：AI Navigation（T3）寻路开销在表现层（兽群 flocking + 聚落局部简化），不进模拟核心，避免污染确定性；须确认寻路不入月级 pass 逻辑。
