Phase 3 出口控制清单（Control Checklist）

Gate-0 测试以 EditMode headless 运行（WorldSim.Tests），CI（-runTests -testFilter Gate0Determinism）红即阻断合入。

D. Phase 4 预制作入口条件

进入 Phase 4（实际写代码 / 建场景 / 装配 prefab）前须满足： 1. ✅ A 类 Gate-0 门禁（G0-1~G0-8）全部通过并接入 CI。 2. ✅ B 类 ADR 选项（U1–U4）经用户确认。 3. ⏳ C 类阻塞项（来自 architecture-review.md §5）：B1 ✅ 已解决（2026-08-12 ADR-002 选项 2 采纳）；B2/B3/B4/B8 ⏳ 转 Phase 4 入口条件（须排期），须 Sprint 1 闭环（与 §C 一致）。 4. ✅ WorldSim.Simulation.* asmdef 创建，且 CI 静态检查"禁止引用 UnityEngine.CoreModule"通过（落实 ADR-001 确定性边界）。 5. ✅ WorldSim.Editor.BuildScript.cs + Gate-0 测试骨架就位（落实 ADR-003）。 6. ✅ New Game 装配 + region-presets.json 导入器可用（落实 B4）。 7. ✅ 模块化开关框架（S7）配置结构就位（MVP 默认关科技/政治/宗教/文化/法律/军事/族群）。 8. ✅ 视觉：NPR 微缩沙盘渲染原型（低多边形+手绘纹理+URP）由林绘澄美术圣经驱动，不与确定性冲突（表现层插值不回写逻辑态）。 9. ☐ com.unity.burst 以固定版本加入 Packages/manifest.json（R-N2 / V0-8 验收项），且 CI 加入 assert-burst-pinned 静态检查，断言 Burst 版本锁定（落实 B2"同 Burst 设置"）。注：manifest 实际修改属 Sprint 1 代码工程动作，本清单仅将其标注为 Phase 4 入口/验收项，不在本文修改 manifest（R-N2 仅文档标注）。
